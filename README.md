# About This Repository

This repository contains my hands-on DevOps journey through real-world infrastructure labs and production-style troubleshooting tasks completed as part of the KodeKloud Engineer program.

The goal of this repository is not just completing tasks — but understanding:
- how systems work,
- why services fail,
- how infrastructure is debugged,
- and how automation improves operations.

Every task is documented with:
- Problem statement
- Step-by-step implementation
- Commands used
- Troubleshooting process
- Key learnings
- Production insights
