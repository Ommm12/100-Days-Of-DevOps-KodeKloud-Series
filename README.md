# About This Repository

This repository documents my complete journey through the **100 Days of DevOps KodeKloud Series**.

The focus of this repository is not just completing tasks — but building real hands-on DevOps skills through:
- infrastructure troubleshooting,
- Linux administration,
- automation,
- CI/CD,
- containerization,
- orchestration,
- and cloud technologies.

Every task includes:
- Problem statement
- Step-by-step implementation
- Commands used
- Troubleshooting process
- Root cause analysis
- Key learnings
- Production insights
