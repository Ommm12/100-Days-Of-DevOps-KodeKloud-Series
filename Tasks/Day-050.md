# Day 50 – Configure Resource Requests and Limits in Kubernetes

---

# Task Overview

The Nautilus DevOps team identified performance issues in Kubernetes workloads due to uncontrolled resource consumption. To ensure applications receive the resources they need while preventing them from consuming excessive CPU and memory, resource requests and limits were introduced.

The task was to create an Apache HTTP Server Pod with specific CPU and Memory requests and limits.

This task introduced one of the most important production Kubernetes concepts: **Resource Management**.

The objective was to:

* Create a Pod named `httpd-pod`
* Use image `httpd:latest`
* Configure container name `httpd-container`
* Set CPU Requests
* Set Memory Requests
* Set CPU Limits
* Set Memory Limits
* Verify Pod deployment

# What are Resource Requests?

Requests define the **minimum resources** Kubernetes guarantees to a container.

Example:

```yaml
requests:
  memory: "15Mi"
  cpu: "100m"
```

Meaning:

```text
Kubernetes reserves:

15 MB Memory
0.1 CPU Core
```

before scheduling the Pod.

---

# What are Resource Limits?

Limits define the **maximum resources** a container can use.

Example:

```yaml
limits:
  memory: "20Mi"
  cpu: "100m"
```

Meaning:

```text
Container cannot exceed:

20 MB Memory
0.1 CPU Core
```

---

# Why Are Resource Limits Important?

Benefits:

* Prevent resource starvation
* Improve cluster stability
* Avoid noisy neighbor problems
* Better workload planning
* Production-grade deployments

# Step 3 – Add Pod Configuration

```yaml
apiVersion: v1
kind: Pod

metadata:
  name: httpd-pod

spec:
  containers:
  - name: httpd-container
    image: httpd:latest

    resources:
      requests:
        memory: "15Mi"
        cpu: "100m"

      limits:
        memory: "20Mi"
        cpu: "100m"
```

# Common Mistakes

## Mistake 1 – Missing Resource Section

Wrong:

```yaml
containers:
- name: httpd-container
  image: httpd:latest
```

Correct:

```yaml
resources:
```

must be defined.

---

## Mistake 2 – Wrong CPU Format

Wrong:

```yaml
cpu: "0.1"
```

Correct:

```yaml
cpu: "100m"
```

---

## Mistake 3 – Wrong Memory Units

Wrong:

```yaml
memory: "15"
```

Correct:

```yaml
memory: "15Mi"
```

---

## Mistake 4 – Limit Lower Than Request

Wrong:

```yaml
requests:
  memory: 20Mi

limits:
  memory: 15Mi
```

Limit must always be equal to or greater than request.
