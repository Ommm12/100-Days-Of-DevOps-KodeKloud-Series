# Day 75 – Jenkins Slave Nodes

---

# Task Overview

The Nautilus DevOps team had recently deployed a Jenkins server to automate CI/CD operations. To distribute workloads and execute jobs directly on application servers, they needed to configure Jenkins SSH Build Agents (formerly known as Slave Nodes).

The objective was to:

* Add all three application servers as Jenkins agents
* Configure SSH-based connectivity
* Assign proper labels
* Configure remote root directories
* Verify agents are online and operational

# Understanding the Problem

Without Jenkins Agents:

```text
Jenkins Controller
        │
        ▼
Runs Everything
```

Problems:

* Resource bottleneck
* Slow builds
* Limited scalability

---

With Jenkins Agents:

```text
              Jenkins Controller
                       │
      ┌────────────────┼────────────────┐
      ▼                ▼                ▼

 App_server_1    App_server_2    App_server_3
    Agent           Agent           Agent
```

Benefits:

* Distributed builds
* Faster execution
* Better scalability

---

# What is a Jenkins Agent?

A Jenkins Agent is a machine that performs build tasks on behalf of the Jenkins Controller.

Responsibilities:

* Execute builds
* Run shell scripts
* Deploy applications
* Perform automation tasks

## Why use Jenkins Agents?

To distribute workloads and improve scalability.

## What are Labels used for?

```text
stapp01

stapp03
```

---

## Difference Between Controller and Agent?

| Controller      | Agent           |
| --------------- | --------------- |
| Manages Jenkins | Executes Jobs   |
| Scheduling      | Build Execution |
| Administration  | Task Processing |

---

## What protocol is used for SSH Agents?

```text
SSH
```

Default Port:

```text
22
```

# Real DevOps Insight

Large Jenkins environments often contain dozens or hundreds of agents:

```text
Controller
     │
     ├── Linux Agents
     ├── Windows Agents
     ├── Docker Agents
     ├── Kubernetes Agents
     └── Cloud Agents
```

This architecture enables high scalability and parallel build execution.
