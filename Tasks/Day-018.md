# Day 18 – WordPress Infrastructure Setup

## Task Overview
The infrastructure team prepared a multi-server environment for hosting a WordPress application.

---

# Objective

- Install Apache and PHP on app servers
- Configure Apache on port 8084
- Install MariaDB on DB server
- Create database and user
- Validate application connectivity

---

# Step-by-Step Implementation

## Step 1: Install Apache and PHP

```bash
sudo yum install -y httpd php php-mysqlnd
```

---

## Step 2: Configure Apache Port

```bash
Listen 8084
```

---

## Step 3: Install MariaDB

```bash
sudo yum install -y mariadb-server
```

---

## Step 4: Create Database and User

```sql
CREATE DATABASE kodekloud_db6;
CREATE USER 'kodekloud_aim'@'%' IDENTIFIED BY 'B4zNgHA7Ya';
GRANT ALL PRIVILEGES ON kodekloud_db6.* TO 'kodekloud_aim'@'%';
```
