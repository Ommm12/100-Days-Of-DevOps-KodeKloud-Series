# Day 28 – Cherry-Pick a Commit from Feature Branch to Master

---

# Task Overview

The Nautilus application development team was working on the repository:

```bash
/opt/ecommerce.git
```

which was cloned under:

```bash
/usr/src/kodekloudrepos/ecommerce
```

The repository contained two branches:

```bash
master
feature
```

A developer was actively working on the `feature` branch, but only one specific commit needed to be moved into the `master` branch without merging the entire branch.

The commit to be transferred had the message:

```bash
Update info.txt
```

The task was to:

- Identify the required commit
- Cherry-pick the commit into the master branch
- Push the changes to the remote repository

# Understanding the Problem

Current Situation:

```text
master
│
├── Commit A
├── Commit B
│
feature
│
├── Commit C
├── Update info.txt
├── Commit D
```

Goal:

```text
master
│
├── Commit A
├── Commit B
├── Update info.txt
```

Notice:

- Entire feature branch is NOT merged
- Only one specific commit is copied

This is exactly what:

```bash
git cherry-pick
```

is designed for.

# Important Concept – Git Cherry-Pick

## What is Git Cherry-Pick?

Cherry-pick allows you to:

- Select a specific commit
- Copy it to another branch
- Avoid merging unrelated changes

---

# Why Not Merge?

Suppose:

Feature Branch:

```text
Commit A
Commit B
Commit C
Update info.txt
Commit D
```

If we merge:

```bash
git merge feature
```

Everything gets merged.

But task requirement:

```text
Only Update info.txt
```

Therefore:

```bash
git cherry-pick
```

is the correct solution.

# Git Merge vs Git Cherry-Pick

| Git Merge | Git Cherry-Pick |
|------------|------------|
| Combines entire branch | Copies specific commit |
| May bring unwanted changes | Selective transfer |
| Creates merge history | Applies single commit |
| Used for branch integration | Used for targeted fixes |

# Common Mistakes During This Task

## Mistake 1 – Cherry-Picking on Wrong Branch

Wrong:

```bash

```

```bash

```

# Interview Questions

## 1. What is Git Cherry-Pick?

Git Cherry-Pick copies a specific commit from one branch and applies it to another branch.

---

## 2. When should you use Cherry-Pick?

- Hotfix deployment
- Bug fixes
- Production patches
- Selective commit transfer

---

## 3. Difference Between Merge and Cherry-Pick?

Merge combines entire branches while Cherry-Pick transfers only selected commits.

---

## 4. Does Cherry-Pick Preserve Commit Content?

Yes.

The commit changes are preserved but a new commit hash is created.
