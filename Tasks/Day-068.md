# Step 3 – Update Package Repository

```bash
apt update
```

### Explanation

Refreshes package metadata before installation.

---

# Step 4 – Install Java

Jenkins requires Java.

```bash
apt install openjdk-17-jdk -y
```

Verify:

```bash
java -version
```

Expected:

```text
OpenJDK 17
```

---

# Step 5 – Add Jenkins Repository Key

```bash
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key | tee \
/usr/share/keyrings/jenkins-keyring.asc > /dev/null
```

---

# Step 6 – Add Jenkins Repository

```bash
echo deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] \
https://pkg.jenkins.io/debian-stable binary/ | tee \
/etc/apt/sources.list.d/jenkins.list > /dev/null
```

---

# Step 7 – Update Repositories

```bash
apt update
```

---

# Step 8 – Install Jenkins

```bash
apt install jenkins -y
```

Expected:

```text
Jenkins Installed Successfully
```

---

# Step 9 – Start Jenkins Service

```bash
service jenkins start
```

---

# Step 10 – Verify Jenkins Service

```bash

```

Expected:

```text
active (running)
```

# Troubleshooting Startup Issues

If Jenkins does not start:

Check status:

```bash
service jenkins status
```

---

Check logs:

```bash
cat /var/log/jenkins/jenkins.log
```

or

```bash
tail -f /var/log/jenkins/jenkins.log
```

---

Common issue:

```text
Java Not Installed
```

Fix:

```bash

```

## Mistake 2 – Repository Not Added

```text

```

Fix:

Add Jenkins repository and run:

```bash
apt update
```

---

## Mistake 3 – Service Not Started

Wrong:

