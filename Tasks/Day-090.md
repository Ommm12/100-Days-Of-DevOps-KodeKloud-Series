# Day 90 – Managing ACLs Using Ansible

---

# Task Overview

The Nautilus DevOps team needed to create files on different application servers while keeping the ownership as `root`. However, specific users and groups required additional permissions on those files using Linux Access Control Lists (ACLs).

Instead of manually configuring permissions on each server, the entire process was automated using Ansible.

The objective was to:

* Create files on specific application servers
* Keep file ownership under root
* Configure ACL permissions using the Ansible ACL module
* Grant different permissions to different users/groups
* Automate everything using a single playbook

# Step 5 – Add Playbook Content

```yaml id="s4s38x"
---
- name: Manage files and ACLs on app servers
  hosts: all
  become: yes

  tasks:

    - name: Ensure directory exists
      file:
        path: /opt/itadmin
        state: directory

    - name: Create blog.txt on stapp01
      file:
        path: /opt/itadmin/blog.txt
        state: touch
      when: inventory_hostname == "stapp01"

    - name: Set ACL for group tony (read)
      acl:
        path: /opt/itadmin/blog.txt
        entity: tony
        etype: group
        permissions: r
        state: present
      when: inventory_hostname == "stapp01"

    - name: Create story.txt on stapp02
      file:
        path: /opt/itadmin/story.txt
        state: touch
      when: inventory_hostname == "stapp02"

    - name: Set ACL for user steve (read+write)
      acl:
        path: /opt/itadmin/story.txt
        entity: steve
        etype: user
        permissions: rw
        state: present
      when: inventory_hostname == "stapp02"

    - name: Create media.txt on stapp03
      file:
        path: /opt/itadmin/media.txt
        state: touch
      when: inventory_hostname == "stapp03"

    - name: Set ACL for group banner (read+write)
      acl:
        path: /opt/itadmin/media.txt
        entity: banner
        etype: group
        permissions: rw
        state: present
      when: inventory_hostname == "stapp03"
```

```yaml id="0w9m3g"

```

Task requires:

```yaml id="j8wd42"

```

Wrong:

```yaml id="jlwmqq"

```

```yaml id="d4k8mu"

```
