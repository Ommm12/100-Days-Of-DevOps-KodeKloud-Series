# Day 46 – Deploy a Multi-Container Application Using Docker Compose

---

# Task Overview

The Nautilus Application Development team completed a PHP-based application that required both a web server and a database server to run together.

To simulate a real-world application stack, Docker Compose was used to deploy multiple interconnected containers from a single configuration file.

The objective was to:

* Create a Docker Compose file
* Deploy a PHP Apache container
* Deploy a MariaDB container
* Configure persistent storage using volume mappings
* Configure database environment variables
* Expose the application using host ports
* Verify both containers are running

# What is Docker Compose?

Docker Compose is a tool that allows multiple containers to be defined and managed using a YAML file.

Instead of running multiple:

```bash
docker run
```

commands, everything can be managed through:

```yaml
docker-compose.yml
```

Benefits:

* Infrastructure as Code

# Step-by-Step Implementation

## Step 1 – Connect to App Server

```bash
ssh banner@stapp03
```

### Explanation

---

# Step 2 – Create Project Directory

```bash
sudo mkdir -p /opt/itadmin
```

### Explanation

Creates the directory where Docker Compose configuration will be stored.

---

# Step 3 – Create Docker Compose File

```bash
sudo vi /opt/itadmin/docker-compose.yml
```

### Explanation

Creates the Compose configuration file.

---

# Step 4 – Add Docker Compose Configuration

```yaml
services:

  web:
    image: php:apache
    container_name: php_host
    ports:
      - "8085:80"
    volumes:
      - /var/www/html:/var/www/html

  db:
    image: mariadb:latest
    container_name: mysql_host
    ports:
      - "3306:3306"
    environment:
      MYSQL_DATABASE: database_host
      MYSQL_USER: devopsuser
      MYSQL_PASSWORD: DevOps@123
      MYSQL_ROOT_PASSWORD: Root@123
    volumes:
      - /var/lib/mysql:/var/lib/mysql
```

---


## Container Name


Required container name.

---

## Port Mapping

```yaml

  - "8085:80"
```

Maps:

```text

       ▼
```

---

## Volume Mapping

```yaml

  - /var/www/html:/var/www/html
```

Maps application files from host into container.

---

# Common Mistakes

## Mistake 1 – Wrong Container Names

Wrong:

```yaml
container_name: php
```

Correct:

```yaml
container_name: php_host
```

---

## Mistake 2 – Missing Database Environment Variables

Without:

```yaml
MYSQL_ROOT_PASSWORD
```

MariaDB will fail to start.

---

## Mistake 3 – Wrong Port Mapping

Wrong:

```yaml
8080:80
```

Correct:

```yaml
8085:80
```

---

## Mistake 4 – Using docker-compose

Many modern systems use:

```bash
docker compose
```

instead of:

```bash
docker-compose
```
