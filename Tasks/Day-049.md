# Day 49 – Deploy Applications with Kubernetes Deployments

---

# Task Overview

The Nautilus DevOps team continued their Kubernetes journey by moving from standalone Pods to Deployments.

While Pods can run applications, they are not ideal for production environments because they do not provide self-healing, scaling, or update capabilities. Kubernetes Deployments solve these problems by managing Pods automatically.

The objective was to:

* Create a Deployment named `nginx`
* Use image `nginx:latest`
* Deploy the application through Kubernetes
* Verify Deployment creation
* Verify Pod creation through Deployment

# What is a Deployment?

A Deployment is a Kubernetes object that manages Pods and ReplicaSets.

It provides:

* Self-healing
* Rolling updates
* Rollbacks
* Scaling
* High availability

---

# Why Use Deployments Instead of Pods?

If a Pod crashes:

```text
Pod Crashed
     │
     ▼
Application Down
```

With a Deployment:

```text
Pod Crashed
     │
     ▼
Deployment Detects Failure
     │
     ▼
New Pod Created
```

Application remains available.

# Step 2 – Create Deployment YAML

```bash
vi deployment.yaml
```

### Explanation

Creates a Kubernetes Deployment manifest.

---

# Step 3 – Add Deployment Configuration

```yaml
apiVersion: apps/v1
kind: Deployment

metadata:
  name: nginx

spec:
  replicas: 1

  selector:
    matchLabels:
      app: nginx

  template:
    metadata:
      labels:
        app: nginx

    spec:
      containers:
      - name: nginx
        image: nginx:latest
```


Tells Deployment which Pods it manages.

```yaml

  app: nginx
```

# Common Mistakes

## Mistake 1 – Missing Image Tag

Wrong:

```yaml
image: nginx
```

Correct:

```yaml
image: nginx:latest
```

---

## Mistake 2 – Wrong Deployment Name

Wrong:

```yaml
name: nginx-deployment
```

Task required:

```yaml
name: nginx
```

---

## Mistake 3 – Selector and Labels Mismatch

Wrong:

```yaml
selector:
  matchLabels:
    app: web
```

Pod:

```yaml
labels:
  app: nginx
```

Deployment will not manage Pods correctly.

---

## Mistake 4 – Incorrect Indentation

Wrong:

```yaml
spec:
containers:
```

Correct:

```yaml
spec:
  containers:
```

YAML is indentation-sensitive.

# Interview Questions

## 1. What is a Kubernetes Deployment?

A Deployment manages Pods and ReplicaSets, providing self-healing, scaling, and rolling updates.

---

## 2. Difference Between Pod and Deployment?

| Pod             | Deployment      |
| --------------- | --------------- |
| Single Unit     | Pod Manager     |
| No Self-Healing | Self-Healing    |
| Manual Updates  | Rolling Updates |
| Not Scalable    | Easily Scalable |

---

## 3. What is a ReplicaSet?

A Kubernetes object that ensures the desired number of Pods are running.
