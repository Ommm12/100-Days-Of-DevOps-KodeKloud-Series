# Day 73 – Jenkins Scheduled Jobs

---

# Task Overview

The xFusionCorp Industries DevOps team was working on implementing a centralized logging solution. Until the complete logging platform was available, they needed a temporary mechanism to collect Apache logs from application servers at regular intervals.

To automate this process, Jenkins was used to periodically copy Apache logs from App Server 3 to the Storage Server.

The objective was to:

* Create a Jenkins job named `copy-logs`
* Schedule the job to run every 12 minutes
* Copy Apache access and error logs
* Transfer logs from App Server 3 to Storage Server
* Store logs under `/usr/src/itadmin`
* Build the job successfully

# Understanding the Problem

Without Automation:

```text
Administrator
      │
      ▼
SSH Login
      │
      ▼
Copy Logs
      │
      ▼
Store Logs
```

Repeated manually every few minutes.

---

With Jenkins:

```text
Jenkins Scheduler
        │
        ▼
Connect to App Server
        │
        ▼
Collect Logs
        │
        ▼
Store on Storage Server
```

Fully automated.

# Common Mistakes

## Mistake 1 – Wrong Cron Expression

Wrong:

```text
*/10 * * * *
```

Required:

```text
*/12 * * * *
```

---

## Mistake 2 – Copying Only One Log

Required:

```text
access_log
error_log
```

Both must be copied.

# Interview Questions

## What is a Jenkins Scheduled Job?

A Jenkins job that runs automatically based on a cron schedule.

---

## What does */12 * * * * mean?

Run every 12 minutes.

---

## Difference Between access_log and error_log?

| access_log    | error_log            |
| ------------- | -------------------- |
| User Requests | Server Errors        |
| HTTP Activity | Failures             |
| Traffic Data  | Troubleshooting Data |

---

## Why centralize logs?

To simplify monitoring, troubleshooting, auditing, and incident response.
