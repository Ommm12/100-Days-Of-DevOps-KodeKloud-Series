# Day 89 – Manage Services Using Ansible

---

# Task Overview

The Nautilus Development team required an FTP service to be installed and managed across all application servers. Instead of manually installing and configuring the service on each server, the DevOps team used Ansible to automate the process.

The objective was to:

* Install the `vsftpd` package on all application servers
* Start the FTP service
* Enable the service to start automatically after reboot
* Manage everything through a single Ansible playbook
* Ensure consistent configuration across all servers

---

# Step 5 – Add Playbook Content

```yaml
---
- name: Install and Manage VSFTPD Service
  hosts: all
  become: yes

  tasks:

    - name: Install vsftpd package
      yum:
        name: vsftpd
        state: present

    - name: Start and Enable vsftpd service
      service:
        name: vsftpd
        state: started
        enabled: yes
```

Save and exit.

# Common Mistakes

## Mistake 1 – Forgetting Enable

Wrong:

```yaml
service:
  name: vsftpd
  state: started
```

Correct:

```yaml
service:
  name: vsftpd
  state: started
  enabled: yes
```

---

## Mistake 2 – Missing Become

Wrong:

```yaml
hosts: all
```

Correct:

```yaml
hosts: all
become: yes
```

---

## Mistake 3 – Wrong Package Name

Wrong:

```yaml
name: ftpd
```

Correct:

```yaml
name: vsftpd
```

# Interview Questions

## 1. What is VSFTPD?

VSFTPD (Very Secure FTP Daemon) is a secure FTP server for Linux systems.

---

## 2. What is the purpose of the Service Module?

It manages Linux services such as starting, stopping, restarting, and enabling them.

---

## 3. What does enabled: yes do?

Ensures the service starts automatically after system reboot.

---

## 4. Difference between state: started and enabled: yes?

| Option         | Purpose               |
| -------------- | --------------------- |
| state: started | Start service now     |
| enabled: yes   | Start service on boot |

---

## 5. Why use Ansible for service management?

It allows centralized, repeatable, and automated management of services across multiple servers.
