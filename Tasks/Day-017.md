# Day 17 – PostgreSQL User and Database Configuration

## Task Overview
The application team required a PostgreSQL database setup for a new application deployment.

---

# Objective

- Create PostgreSQL database user
- Configure password authentication
- Create application database
- Grant full privileges

---

# Step-by-Step Implementation

## Step 1: Switch to PostgreSQL User

```bash
sudo -i -u postgres
```

---

## Step 2: Open PostgreSQL Shell

```bash
psql
```

---

## Step 3: Create User

```sql
CREATE USER kodekloud_pop WITH PASSWORD '8FmzjvFU6S';
```

---

## Step 4: Create Database

```sql
CREATE DATABASE kodekloud_db10;
```

---

## Step 5: Grant Permissions

```sql
GRANT ALL PRIVILEGES ON DATABASE kodekloud_db10 TO kodekloud_pop;
```

---

# Key Learnings

- PostgreSQL administration
- Database access control
- User privilege management
- SQL-based configuration

---

# Final Outcome

- PostgreSQL user created
- Database configured successfully
- Application access permissions granted
