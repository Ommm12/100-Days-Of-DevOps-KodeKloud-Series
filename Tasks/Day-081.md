# Day 81 – Jenkins Multistage Pipeline Deployment

# Task Overview

The Nautilus application team developed a static website and wanted an automated deployment process using Jenkins Pipeline.

The objective was to:

* Configure App Server 1 as a Jenkins Agent
* Connect Jenkins with Gitea repository
* Update website content in source control
* Create a Jenkins Multistage Pipeline
* Deploy application automatically
* Validate deployment through Load Balancer
* Ensure website is accessible after deployment

# What is Jenkins Pipeline?

A Jenkins Pipeline is a collection of automated stages that define how software is:

* Built
* Tested
* Deployed

Using code.

This approach is called:

```text
Pipeline as Code
```

---

# Why DevOps Teams Use Pipelines

Benefits:

* Faster deployments
* Repeatable process
* Reduced manual errors
* Automated testing
* Consistent delivery

# Pipeline Script

```groovy
pipeline {
    agent {
        label 'stapp01'
    }

    stages {

        stage('Deploy') {
            steps {
                script {
                    sh '''
                    cd /var/www/html
                    git pull origin master
                    '''
                }
            }
        }

        stage('Test') {
            steps {
                script {
                    sh '''
                    curl -f http://stlb01:8091
                    '''
                }
            }
        }

    }
}
```

# Common Mistakes

## Mistake 1 – Agent Offline

Cause:

```text
Java not installed
```

Fix:

```bash
yum install java-17-openjdk -y
```

---

## Mistake 2 – SSH Connection Failure

Cause:

```text
Host key verification failed
```

Fix:

```bash
ssh stapp01
```

Accept fingerprint.

---

## Mistake 3 – Pipeline Runs on Wrong Node

Wrong:

```groovy
agent any
```

Correct:

```groovy
agent {
    label 'stapp01'
}
```

---

## Mistake 4 – Application Loads but Task Fails

Cause:

```text
Only index.html deployed
Assets missing
```

Always verify complete application deployment.

# Interview Questions

## 1. What is a Jenkins Pipeline?

A Jenkins Pipeline automates build, test, and deployment processes using code.

---

## 2. What is a Jenkins Agent?

A Jenkins Agent is a machine that executes pipeline jobs on behalf of the Jenkins Controller.

---

## 3. Why use Multistage Pipelines?

To separate deployment workflow into logical stages such as:

* Build
* Test
* Deploy

---

## 4. What does curl -f do?

```bash
curl -f URL
```

Fails immediately if HTTP request returns an error code.

---

## 5. Why use Jenkins Agents?

To distribute workload and execute jobs closer to deployment targets.
