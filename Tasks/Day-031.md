# Understanding the Problem

A stash is a temporary storage area where Git saves unfinished work.

Example:

Before Stash:

```text
Modified File A
Modified File B
```

Developer runs:

```bash
git stash
```

Git stores changes safely:

```text
stash@{0}
stash@{1}
stash@{2}
```

Now the changes can be restored later.

---

# What is Git Stash?

Git Stash allows developers to:

- Save unfinished work
- Switch branches safely
- Pull updates without committing incomplete code

Think of it as:

```text
Temporary Clipboard for Git Changes
```

# Apply vs Pop

| Apply | Pop |
|---------|---------|
| Restores stash | Restores stash |
| Keeps stash | Removes stash |
| Safer | Commonly used |

Example:

```bash
git stash apply stash@{1}
```

stash remains.

---

Example:

```bash
git stash pop
```

stash removed.

# Common Mistakes

## Mistake 1 – Restoring Wrong Stash

Wrong:

```bash
git stash apply stash@{0}
```

Always verify:

```bash
git stash list
```

first.

---

## Mistake 2 – Using Pop Instead of Apply

Wrong:

```bash
git stash pop
```

This removes stash immediately.

Task specifically required:

```bash
stash@{1}
```

---

## Mistake 3 – Forgetting Commit

Restoring stash does not automatically create a commit.

You must:

```bash
git add .
git commit
```

---

## Mistake 4 – Forgetting Push

Local commit alone is insufficient.

Always push:

```bash
git push origin master
```

# Interview Questions

## 1. What is Git Stash?

Git Stash temporarily stores uncommitted changes for later use.

---

## 2. Why would developers use Git Stash?

To save unfinished work without creating unnecessary commits.

---

## 3. Difference Between Apply and Pop?

Apply restores stash and keeps it.

Pop restores stash and removes it.

---

## 4. How do you list all stashes?

```bash
git stash list
```

---

## 5. Can multiple stashes exist?

Yes.

Example:

```bash
stash@{0}
stash@{1}
stash@{2}
```
