# Day 25 – Merge Feature Branch into Master Branch

---

# Task Overview

The Nautilus application development team was working on the repository:

```bash
/opt/news.git
```

The repository was cloned under:

```bash
/usr/src/kodekloudrepos/news
```

The team wanted to:
- Create a new branch
- Add a file into the repository
- Commit changes
- Merge changes back into the master branch
- Push updates to the remote repository

---

# Requirements

1. Create a new branch named:

```bash
devops
```

2. Copy the following file into the repository:

```bash
/tmp/index.html
```

3. Commit the file in the new branch
4. Merge the branch into `master`
5. Push both branches to origin

---

# Infrastructure Details

| Server | Hostname | User |
|---|---|---|
| Storage Server | ststor01.stratos.xfusioncorp.com | natasha |

---

# Step-by-Step Implementation

## Step 1 – Connect to Storage Server

```bash
ssh natasha@ststor01
```

---

# Step 2 – Navigate to Repository

```bash
cd /usr/src/kodekloudrepos/news
```

### Explanation

Moves into the cloned Git repository where branch and merge operations will be performed.

---

# Step 3 – Create New Branch

```bash
sudo git checkout -b devops
```

### Explanation

Creates a new branch named `devops` and switches to it.

---

# Step 4 – Copy Required File

```bash
sudo cp /tmp/index.html /usr/src/kodekloudrepos/news/
```

### Explanation

Copies the required file into the repository directory.

### Why `sudo` Was Needed

The repository directory was owned by `root`, so elevated privileges were required to copy files into it.

---

# Step 5 – Verify File

```bash
ls
```

### Expected Output

```bash
index.html
```

---

# Step 6 – Add File to Git Staging Area

```bash
sudo git add index.html
```

### Explanation

The `git add` command stages the file for commit.

---

# Step 7 – Commit Changes

```bash
sudo git commit -m "Added index.html file"
```

### Explanation

Creates a Git commit containing the staged changes.

### Command Breakdown

| Part | Meaning |
|---|---|
| `git commit` | Create commit |
| `-m` | Commit message |
| `"Added index.html file"` | Commit description |

---

# Step 8 – Push DevOps Branch

```bash
sudo git push origin devops
```

### Explanation

Uploads the new branch and its commits to the remote repository.

---

# Step 9 – Switch to Master Branch

```bash
sudo git checkout master
```

---

# Step 10 – Merge DevOps Branch into Master

```bash
sudo git merge devops
```

### Explanation

Merges changes from the `devops` branch into `master`.

---

# Step 11 – Push Master Branch

```bash
sudo git push origin master
```

### Explanation

Pushes merged changes to the remote master branch.

---

# Important Concept – Git Merge

## What is Git Merge?

`git merge` combines changes from one branch into another branch.

Example:

```text
master ← merge ← devops
```

---

# Real DevOps Insight

Branch merging is widely used in:
- CI/CD pipelines
- Feature deployments
- Team collaboration
- Release workflows

Typical workflow:

```text
Create Branch → Develop Feature → Commit → Merge → Deploy
```
