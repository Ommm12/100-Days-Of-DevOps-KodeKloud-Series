# Day 20 – Nginx and PHP-FPM Integration

## Task Overview
The development team planned to deploy a PHP-based application using Nginx and PHP-FPM.

---

# Objective

- Install Nginx
- Install PHP-FPM 8.2
- Configure Unix socket communication
- Integrate Nginx with PHP-FPM
- Validate PHP application execution

---

# Step-by-Step Implementation

## Step 1: Install Nginx

```bash
sudo yum install -y nginx
```

---

## Step 2: Install PHP 8.2

```bash
sudo yum module reset php -y
sudo yum module enable php:8.2 -y
sudo yum install -y php php-fpm
```

---

## Step 3: Configure PHP-FPM

```bash
sudo vi /etc/php-fpm.d/www.conf
```

Set:

```bash
listen = /var/run/php-fpm/default.sock
```

---

## Step 4: Configure Nginx

Configured Nginx server block with FastCGI integration.

---

## Step 5: Start Services

```bash
sudo systemctl start php-fpm
sudo systemctl start nginx
```

---

## Step 6: Validate Application

```bash
curl http://stapp01:8099/index.php
```

---

# Key Learnings

- Nginx and PHP-FPM integration
- FastCGI architecture
- Unix socket communication
- Production PHP deployment

---

# Final Outcome

- PHP application deployed successfully
- Nginx integrated with PHP-FPM
