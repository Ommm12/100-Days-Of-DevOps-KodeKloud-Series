# Day 96 – Create EC2 Instance Using Terraform

---

# Task Overview

After creating networking and security resources in AWS, the Nautilus DevOps team moved to the next critical step: launching a virtual machine in the cloud.

For this task, Terraform was used to provision an EC2 instance, create a new SSH key pair, and attach the default security group. This represents a real-world Infrastructure as Code workflow where compute resources are deployed automatically instead of manually through the AWS Console.

The objective was to:

* Create an EC2 instance
* Use a specific Amazon Linux AMI
* Use instance type `t2.micro`
* Create an RSA key pair
* Attach the default security group
* Tag the instance as `datacenter-ec2`
* Manage everything using Terraform

# Step 3 – Add Terraform Configuration

```hcl
terraform {
  required_providers {
    aws = {
      source = "hashicorp/aws"
    }
  }
}

provider "aws" {
  region = "us-east-1"
}

resource "tls_private_key" "datacenter_kp" {
  algorithm = "RSA"
  rsa_bits  = 2048
}

resource "aws_key_pair" "datacenter_kp" {
  key_name   = "datacenter-kp"
  public_key = tls_private_key.datacenter_kp.public_key_openssh
}

data "aws_security_group" "default" {
  name = "default"
}

resource "aws_instance" "datacenter_ec2" {

  ami           = "ami-0c101f26f147fa7fd"

  instance_type = "t2.micro"

  key_name      = aws_key_pair.datacenter_kp.key_name

  vpc_security_group_ids = [
    data.aws_security_group.default.id
  ]

  tags = {
    Name = "datacenter-ec2"
  }
}
```

Save and exit.
