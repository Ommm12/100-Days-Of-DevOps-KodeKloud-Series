# Day 66 – Deploy MySQL on Kubernetes

---

# Task Overview

The Nautilus DevOps team needed to deploy a MySQL database server on a Kubernetes cluster. Since databases store critical data, the deployment required persistent storage, secure credential management using Kubernetes Secrets, and external access through a NodePort Service.

The objective was to:

* Create a PersistentVolume named `mysql-pv`
* Create a PersistentVolumeClaim named `mysql-pv-claim`
* Create Kubernetes Secrets for database credentials
* Deploy a MySQL container using persistent storage
* Configure environment variables from Secrets
* Expose MySQL using a NodePort Service
* Ensure data persists across Pod restarts

# Step 15 – Add Deployment Configuration

```yaml
apiVersion: apps/v1
kind: Deployment

metadata:
  name: mysql-deployment

spec:
  replicas: 1

  selector:
    matchLabels:
      app: mysql

  template:
    metadata:
      labels:
        app: mysql

    spec:
      containers:
      - name: mysql
        image: mysql:8

        env:
        - name: MYSQL_ROOT_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-root-pass
              key: password

        - name: MYSQL_DATABASE
          valueFrom:
            secretKeyRef:
              name: mysql-db-url
              key: database

        - name: MYSQL_USER
          valueFrom:
            secretKeyRef:
              name: mysql-user-pass
              key: username

        - name: MYSQL_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-user-pass
              key: password

        ports:
        - containerPort: 3306

        volumeMounts:
        - name: mysql-storage
          mountPath: /var/lib/mysql

      volumes:
      - name: mysql-storage
        persistentVolumeClaim:
          claimName: mysql-pv-claim
```

# Common Mistakes

## Mistake 1 – Secret Key Name Mismatch

Wrong:

```yaml
key: rootpassword
```

Correct:

```yaml
key: password
```

---

## Mistake 2 – PVC Size Mismatch

Wrong:

```yaml
PVC: 500Mi
PV: 250Mi
```

Result:

```text
Pending
```

---

## Mistake 3 – Missing Volume Mount

Without:

```yaml
volumeMounts:
```

MySQL data will not persist.

---

## Mistake 4 – Wrong NodePort

Wrong:

```yaml
30000
```

Correct:

```yaml
30007
```

# Real DevOps Insight

Databases are stateful applications.

Without persistent storage:

```text
Pod Restart
     │
     ▼
Data Lost
```

With PVs and PVCs:

```text
Pod Restart
     │
     ▼
Data Preserved
```

This is why persistent storage and secure secret management are critical components of production Kubernetes database deployments.
