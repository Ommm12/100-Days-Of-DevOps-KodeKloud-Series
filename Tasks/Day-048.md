# Day 48 – Deploy a Pod in Kubernetes Cluster

---

# Task Overview

The Nautilus DevOps team started working with Kubernetes to manage containerized applications more efficiently. The requirement was to create a Pod running an Apache HTTP Server container using the latest httpd image.

This task introduced the most fundamental Kubernetes object: the **Pod**. Every application running in Kubernetes ultimately runs inside a Pod.

The objective was to:

* Create a Pod named `pod-httpd`
* Use image `httpd:latest`
* Configure container name as `httpd-container`
* Apply label `app=httpd_app`
* Verify Pod deployment

# What is a Pod?

A Pod is the smallest Kubernetes object that can run one or more containers.

Example:

```text
Pod
 │
 └── Container
```

or

```text
Pod
 │
 ├── Container 1
 └── Container 2
```

# Step-by-Step Implementation

## Step 1 – Connect to Jump Host

```bash
ssh thor@jump-host
```

### Explanation

Connects to the jump host configured to manage the Kubernetes cluster.

---

# Step 2 – Create Pod Definition File

```bash
vi pod.yaml
```

### Explanation

Creates a YAML manifest describing the Pod.

---

# Step 3 – Add Pod Configuration

```yaml
apiVersion: v1
kind: Pod

metadata:
  name: pod-httpd
  labels:
    app: httpd_app

spec:
  containers:
  - name: httpd-container
    image: httpd:latest
```


3. Schedules Pod to a Node
4. Pulls Image
5. Creates Container

# Common Mistakes

## Mistake 1 – Missing Image Tag

Wrong:

```yaml
image: httpd
```

Correct:

```yaml
image: httpd:latest
```

---

## Mistake 2 – Wrong Pod Name

Wrong:

```yaml
name: httpd
```

Correct:

```yaml
name: pod-httpd
```

---

## Mistake 3 – Incorrect Label

Wrong:

```yaml
app: apache
```

Correct:

```yaml
app: httpd_app
```

---

## Mistake 4 – YAML Indentation Errors

Wrong:

```yaml
spec:
containers:
```

Correct:

```yaml
spec:
  containers:
```

YAML is indentation-sensitive.
