# Day 15 – Nginx SSL Configuration

## Task Overview
The application team required secure HTTPS communication on App Server 3 using Nginx and self-signed SSL certificates.

---

# Objective

- Install and configure Nginx
- Configure HTTPS using SSL certificate
- Deploy custom index page
- Validate secure connectivity

---

# Step-by-Step Implementation

## Step 1: Install Nginx

```bash
sudo yum install -y nginx
```

---

## Step 2: Move SSL Files

```bash
sudo mv /tmp/nautilus.crt /etc/nginx/
sudo mv /tmp/nautilus.key /etc/nginx/
```

---

## Step 3: Configure Nginx

```bash
sudo vi /etc/nginx/nginx.conf
```

Configured HTTPS server block with SSL paths.

---

## Step 4: Create Index File

```bash
echo "Welcome!" | sudo tee /usr/share/nginx/html/index.html
```

---

## Step 5: Start Nginx

```bash
sudo systemctl start nginx
sudo systemctl enable nginx
```

---

## Step 6: Validate HTTPS

```bash
curl -Ik https://stapp03
```
