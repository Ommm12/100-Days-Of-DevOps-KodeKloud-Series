# 🚀 Day 10 – Website Backup Automation Script

## 📌 Task Overview
The production support team at **xFusionCorp Industries** needed to automate website backup operations for one of their static websites hosted on **App Server 2**.

To simplify recurring backup tasks and ensure data redundancy, a Bash automation script needed to:
- Compress website files
- Store backups locally
- Transfer backups to the centralized backup server
- Perform operations without password prompts

### 🎯 Objective

Create a Bash script named:

```bash
beta_backup.sh
```

that performs the following operations:

- Create a zip archive of the website directory
- Store the backup locally
- Copy the backup to the Nautilus Backup Server
- Ensure password-less transfer using SSH keys
- Avoid using `sudo` inside the script

# 🛠️ Step-by-Step Implementation

---

# 🔹 Step 1: Connect to App Server 2

```bash
ssh steve@stapp02.stratos.xfusioncorp.com
```

### 📖 Explanation
Use SSH to securely connect to the target application server where the backup automation script will be created.

---

# 🔹 Step 2: Install zip Package

```bash
sudo yum install -y zip
```

### 📖 Explanation
The `zip` utility is required to compress the website files into an archive.

---

# 🔹 Step 3: Create Script Directory

```bash
sudo mkdir -p /scripts
```

### 📖 Explanation
Creates the directory where the automation script will be stored.

---

# 🔹 Step 4: Configure Password-less SSH Authentication

Generate SSH key:

```bash
ssh-keygen -t rsa
```

Copy public key to backup server:

```bash
ssh-copy-id clint@stbkp01.stratos.xfusioncorp.com
```

### 📖 Explanation
This enables secure password-less file transfer using SSH keys.

---

# 🔹 Step 5: Create Backup Script

```bash
sudo vi /scripts/beta_backup.sh
```

Add the following script:

```bash
#!/bin/bash

zip -r /backup/xfusioncorp_beta.zip /var/www/html/beta

scp /backup/xfusioncorp_beta.zip clint@stbkp01.stratos.xfusioncorp.com:/backup/
```

---

# 📖 Script Explanation

## Create ZIP Backup
```bash
zip -r /backup/xfusioncorp_beta.zip /var/www/html/beta
```

- `-r` → Recursive compression
- Compresses website directory into:

```bash
/backup/xfusioncorp_beta.zip
```

---

## Transfer Backup to Backup Server
```bash
scp /backup/xfusioncorp_beta.zip clint@stbkp01.stratos.xfusioncorp.com:/backup/
```

Securely copies the backup archive to the centralized backup server.

---

# 🔹 Step 6: Grant Execute Permission

```bash
sudo chmod +x /scripts/beta_backup.sh
```

### 📖 Explanation
Makes the script executable.

---

# 🔹 Step 7: Execute the Script

```bash
/scripts/beta_backup.sh
```

### 📖 Explanation
Runs the automation workflow:
- Creates backup
- Transfers archive remotely

---

# 🔹 Step 8: Verify Backup Creation

## Local Backup Verification
```bash
ls -l /backup/
```

## Backup Server Verification
```bash
ssh clint@stbkp01.stratos.xfusioncorp.com
ls -l /backup/
```

### 📖 Explanation
Confirms:
- Backup archive exists locally
- Backup was successfully transferred to backup server
