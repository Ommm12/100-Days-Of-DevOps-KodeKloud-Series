# Day 27 – Revert a Git Commit

---

# Task Overview

The Nautilus application development team reported that an incorrect commit had recently been pushed to the repository. Instead of rewriting commit history, the requirement was to safely undo the latest changes while preserving repository history.

Repository Location:

```bash
/usr/src/kodekloudrepos/official
```

### Requirements

- Revert the latest commit (`HEAD`)
- Restore repository state to the previous commit
- Use the commit message:

```bash
revert official message
```

- Do not delete commit history
- Create a new revert commit

# Important Concept – Git Revert

## What is Git Revert?

`git revert` safely undoes changes by creating a new commit.

Unlike reset:

- History is preserved
- Safe for shared repositories
- Preferred in production environments

---

# Git Revert vs Git Reset

| Git Revert | Git Reset |
|------------|------------|
| Creates new commit | Moves branch pointer |
| Safe for teams | Can rewrite history |
| Preserves history | Can remove history |
| Production friendly | Risky on shared repos |


Using:

```bash

```

In production environments:

- Failed releases

# Common Mistakes During This Task

## Mistake 1 – Reverting Twice

Example:

```bash
git revert HEAD
git revert HEAD
```

Result:

- First revert removes changes
- Second revert re-applies changes

This often causes task failures.

---

## Mistake 2 – Using Git Reset

Wrong:

```bash
git reset --hard HEAD~1
```

Reason:

- Removes commit history
- Not requested by task

---

## Mistake 3 – Wrong Commit Message

Required:

```bash
revert official message
```

Wrong:

```bash
Revert Official Message
```

The task validator is case-sensitive.

# Interview Questions

## 1. What does `git revert` do?

Creates a new commit that reverses changes introduced by a previous commit.

---

## 2. Why is Git Revert safer than Git Reset?

Because it preserves repository history and is safe for collaborative environments.

---

## 3. Does Git Revert delete commits?

No.

It creates a new commit that undoes previous changes.

- Production rollbacks
