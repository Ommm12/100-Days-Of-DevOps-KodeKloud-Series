#  Day 05 – SELinux Installation and Configuration

##  Task Overview
Following a security audit, the security team at **xFusionCorp Industries** decided to strengthen the infrastructure security posture by implementing **SELinux (Security-Enhanced Linux)** on the application servers.

As part of the initial testing phase, the team required SELinux packages to be installed and configured on **App Server 3**.

###  Objective
- Install required SELinux packages  
- Permanently disable SELinux  
- No reboot required immediately  
- Ensure SELinux remains disabled after the next reboot  

---

#  Why This Task Matters

SELinux is a Linux kernel security module that provides:
- Mandatory Access Control (MAC)
- Process isolation
- Fine-grained security policies
- Protection against unauthorized access

In production systems, SELinux helps:
- Reduce attack surface
- Restrict unauthorized process behavior
- Improve system-level security

Understanding SELinux configuration is an important Linux administration and DevOps skill.

---

#  Step-by-Step Implementation

---

# 🔹 Step 1: Connect to App Server 3

```bash
ssh banner@stapp03.stratos.xfusioncorp.com
```

###  Explanation
Use SSH to securely access the target application server where SELinux configuration changes need to be applied.

---

# 🔹 Step 2: Install SELinux Packages

```bash
sudo yum install -y selinux-policy selinux-policy-targeted policycoreutils
```

###  Explanation
This installs the required SELinux packages and management utilities.

### Installed Components

| Package | Purpose |
|---------|---------|
| `selinux-policy` | Core SELinux security policies |
| `selinux-policy-targeted` | Default targeted protection policies |
| `policycoreutils` | SELinux management tools |

---

# 🔹 Step 3: Verify Current SELinux Status

```bash
sestatus
```

###  Explanation
Displays:
- SELinux current mode
- Policy information
- Whether SELinux is enabled or disabled

Example output:

```bash
SELinux status: enabled
Current mode: enforcing
```

---

# 🔹 Step 4: Configure SELinux to be Permanently Disabled

Open SELinux configuration file:

```bash
sudo vi /etc/selinux/config
```

Find:

```bash
SELINUX=enforcing
```

Change it to:

```bash
SELINUX=disabled
```

---

# 🔹 Step 5: Save Configuration Changes

Inside `vi` editor:

```bash
Esc
:wq
Enter
```

###  Explanation
- `Esc` → Exit insert mode  
- `:wq` → Save and quit  

---

# 🔹 Step 6: Verify Configuration File

```bash
cat /etc/selinux/config
```

###  Explanation
Ensure the configuration file now contains:

```bash
SELINUX=disabled
```

This confirms SELinux will remain disabled after the next reboot.

---

#  Additional Verification Commands

## Check SELinux Status
```bash
sestatus
```

## Display Current SELinux Mode
```bash
getenforce
```

## Temporarily Disable SELinux (Runtime Only)
```bash
sudo setenforce 0
```

#  Security Considerations

- SELinux provides strong kernel-level security controls
- Disabling SELinux reduces security protections
- In production, SELinux should ideally remain enabled with properly configured policies
- Temporary disabling is sometimes required during testing or troubleshooting
