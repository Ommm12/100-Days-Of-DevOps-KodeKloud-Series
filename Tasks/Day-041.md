# Day 41 – Build a Custom Apache Docker Image Using Ubuntu 24.04

---

# Task Overview

The Nautilus DevOps team received a requirement from the development team to create a custom Docker image for one of their web applications.

The image needed to be built using Ubuntu 24.04 as the base image and Apache web server had to be configured to listen on a custom port instead of the default HTTP port.

The objective was to:

* Create a Dockerfile
* Use Ubuntu 24.04 as the base image
* Install Apache2 inside the image
* Configure Apache to run on port 3001
* Build a custom Docker image successfully

# Step 3 – Create Dockerfile

```bash
vi Dockerfile
```

### Explanation

Creates the Docker build definition file.

---

# Step 4 – Add Dockerfile Configuration

```dockerfile
FROM ubuntu:24.04

RUN apt-get update && \
    apt-get install apache2 -y

RUN sed -i 's/80/3001/g' /etc/apache2/ports.conf

EXPOSE 3001

CMD ["/usr/sbin/apachectl","-D","FOREGROUND"]
```

# Dockerfile Breakdown

## Base Image

```dockerfile

```

Uses Ubuntu 24.04 as the foundation image.

---

## Install Apache

```dockerfile
RUN apt-get update && \
    apt-get install apache2 -y
```

Installs Apache web server packages.

### Command Breakdown

| Command         | Purpose               |
| --------------- | --------------------- |
| apt-get update  | Refresh package cache |
| apt-get install | Install package       |
| apache2         | Apache Web Server     |
| -y              | Auto confirm          |

---

## Configure Custom Port

```dockerfile
RUN sed -i 's/80/3001/g' /etc/apache2/ports.conf
```

Changes Apache listening port from:

```text
80
```

to:

```text
3001
```

### sed Breakdown

| Option | Meaning            |
| ------ | ------------------ |
| sed    | Stream editor      |
| -i     | Edit file in place |
| s      | Substitute         |
| 80     | Old value          |
| 3001   | New value          |

---

## Expose Port

```dockerfile
EXPOSE 3001
```

Documents the port used by the container.

---

## Start Apache

```dockerfile
CMD ["/usr/sbin/apachectl","-D","FOREGROUND"]
```

Starts Apache in foreground mode.

Docker containers require the main process to stay active.

# Common Mistakes

## Mistake 1 – Forgetting apt-get update

Wrong:

```dockerfile
RUN apt-get install apache2 -y
```

Correct:

```dockerfile
RUN apt-get update && apt-get install apache2 -y
```

---

## Mistake 2 – Apache Running in Background

Wrong:

```dockerfile
CMD apachectl start
```

Container exits immediately.

Correct:

```dockerfile
CMD ["/usr/sbin/apachectl","-D","FOREGROUND"]
```

---

## Mistake 3 – Incorrect Port Mapping

Wrong:

```bash
docker run -p 80:3001
```

Correct:

```bash
docker run -p 3001:3001
```

---

## Mistake 4 – Editing Unnecessary Apache Files

Task only required changing:

```text
ports.conf
```

Avoid modifying:

* Document Root
* Virtual Hosts
* Other Apache settings
