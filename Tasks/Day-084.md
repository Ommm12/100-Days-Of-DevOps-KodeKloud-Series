# Day 84 – Copy Data to App Servers Using Ansible

---

# Task Overview

The Nautilus DevOps team needed to distribute a static file from the Jump Host to all application servers using Ansible. Instead of manually copying files to each server, the objective was to automate the process through a playbook.

The objective was to:

* Create an Ansible inventory containing all application servers
* Create a playbook to copy a file to multiple servers
* Use Ansible's copy module
* Deploy the file to all application servers simultaneously
* Validate successful file distribution

# What is the Ansible Copy Module?

The Copy Module transfers files from:

```text
Ansible Controller
        │
        ▼
Managed Node
```

It works similarly to:

```bash
scp
```

but is fully automated.

# Step 4 – Create Playbook

```bash
vi playbook.yml
```

---

# Step 5 – Add Playbook Content

```yaml
---
- name: Copy file to all application servers
  hosts: all
  become: yes

  tasks:

    - name: Ensure destination directory exists
      file:
        path: /opt/sysops
        state: directory

    - name: Copy index.html
      copy:
        src: /usr/src/sysops/index.html
        dest: /opt/sysops/index.html
```

Save file.

# Common Mistakes

## Mistake 1 – Missing Directory

Error:

```text
Destination directory does not exist
```

Fix:

```yaml
file:
  path: /opt/sysops
  state: directory
```

---

## Mistake 2 – Wrong Source Path

Wrong:

```yaml
src: /usr/src/index.html
```

Correct:

```yaml
src: /usr/src/sysops/index.html
```

---

## Mistake 3 – Missing Become

Without:

```yaml
become: yes
```

Writing to:

```bash
/opt
```

may fail.

---

## Mistake 4 – Using Single Host

Wrong:

```yaml
hosts: stapp01
```

Correct:

```yaml
hosts: all
```

Task requires all app servers.

# Interview Questions

## 1. What does the Ansible Copy Module do?

It copies files from the Ansible controller to managed nodes.

---

## 2. Why use hosts: all?

To execute tasks on every host defined in the inventory.

---

## 3. What is the purpose of become: yes?

Provides elevated privileges for tasks requiring administrative access.

---

## 4. What is the difference between SCP and Ansible Copy?

| SCP           | Ansible Copy           |
| ------------- | ---------------------- |
| Manual        | Automated              |
| Single Server | Multiple Servers       |
| No Playbooks  | Infrastructure as Code |

---

## 5. How do you verify a copied file?

```bash
ansible -i inventory all -a "ls -l /path/file"
```
