# Day 13 – IPTables Installation and Firewall Configuration

## Task Overview
The security team identified that Apache port 6400 was publicly accessible on all application servers without firewall restrictions.

The objective was to:
- Install IPTables
- Restrict access to port 6400
- Allow access only from the Load Balancer server
- Persist firewall rules after reboot

---

# Objective

- Install IPTables on all app servers
- Block incoming traffic on port 6400
- Allow only LBR host access
- Persist firewall configuration

---

# Why This Task Matters

Firewall configuration is critical for:
- Restricting unauthorized access
- Securing production services
- Controlling traffic flow
- Reducing attack surface

---

# Step-by-Step Implementation

## Step 1: Install IPTables

```bash
sudo yum install -y iptables-services
```

---

## Step 2: Start and Enable IPTables

```bash
sudo systemctl start iptables
sudo systemctl enable iptables
```

---

## Step 3: Allow Access from LBR

```bash
sudo iptables -A INPUT -p tcp -s <LBR-IP> --dport 6400 -j ACCEPT
```

---

## Step 4: Block All Other Access

```bash
sudo iptables -A INPUT -p tcp --dport 6400 -j DROP
```

---

## Step 5: Save Rules

```bash
sudo service iptables save
```

---

## Step 6: Verify Rules

```bash
sudo iptables -L -n
```
