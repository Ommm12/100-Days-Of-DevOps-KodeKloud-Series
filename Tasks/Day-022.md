# Day 22 – Clone Git Repository on Storage Server

---

# Task Overview

The Nautilus development team requested a copy of an existing Git repository on the Storage Server in Stratos Datacenter.

### Requirements

- Repository to clone:

```bash
/opt/ecommerce.git
```

- Clone destination:

```bash
/usr/src/kodekloudrepos
```

- Perform the task using the `natasha` user
- Do not modify repository permissions or existing directories

---

# Infrastructure Details

| Server | Hostname | User |
|---|---|---|
| Storage Server | ststor01.stratos.xfusioncorp.com | natasha |

---

# Step-by-Step Implementation

## Step 1 – Connect to the Storage Server

```bash
ssh natasha@ststor01
```

### Explanation

The `ssh` command is used to securely connect to the remote storage server where the repository cloning operation will be performed.

---

# Step 2 – Navigate to the Target Directory

```bash
cd /usr/src/kodekloudrepos
```

### Explanation

This directory is the required location where the repository must be cloned.

The `cd` command changes the current working directory.

---

# Step 3 – Clone the Git Repository

```bash
git clone /opt/ecommerce.git
```

### Explanation

The `git clone` command creates a local copy of an existing Git repository.

### Command Breakdown

| Part | Meaning |
|---|---|
| `git clone` | Clone an existing repository |
| `/opt/ecommerce.git` | Source repository path |

---

# Step 4 – Verify Repository Cloning

```bash
ls -l /usr/src/kodekloudrepos
```

### Expected Output

```bash
drwxr-xr-x 3 natasha natasha ecommerce
```

### Explanation

This confirms that the repository has been successfully cloned into the target directory.

---

# Step 5 – Verify Git Repository Contents

```bash
cd ecommerce
git status
```

### Expected Output

```bash
On branch master
nothing to commit, working tree clean
```

### Explanation

The `git status` command checks the current state of the repository and verifies that the working tree is clean.

---

# Important Concept – Git Clone

## What Does `git clone` Do?

The `git clone` command:

- Copies the entire repository
- Downloads commit history
- Creates a working directory
- Automatically configures remote origin

---

# Default Remote Created During Clone

After cloning, Git automatically creates a remote named:

```bash
origin
```

You can verify using:

```bash
git remote -v
```

### Example Output

```bash
origin  /opt/ecommerce.git (fetch)
origin  /opt/ecommerce.git (push)
```

# Interview Questions You Can Answer Now

### 1. What does `git clone` do?

`git clone` creates a complete local copy of a remote or local Git repository including commit history and working files.

---

### 2. What is the default remote name after cloning?

The default remote name is:

```bash
origin
```

---

### 3. Difference between cloning and copying a repository?

| Cloning | Copying |
|---|---|
| Preserves Git history | Only copies files |
| Creates remote connection | No Git tracking |
| Supports version control | No version control |
