#  Day 02 – Temporary User Setup with Expiry Date

##  Task Overview
As part of a temporary assignment on the Nautilus project, the system administration team at **xFusionCorp Industries** needed to create a user account with limited-time access.

To maintain proper access control and security compliance, the account had to automatically expire after a specific date.

###  Objective
Create a user named `yousuf` on **App Server 2** with an expiry date set to:

```bash
2027-02-17
```

---

#  Why This Task Matters

In real production environments, temporary employees, contractors, interns, or third-party vendors should never have permanent access to infrastructure.

Setting account expiration dates helps:
- Reduce security risks
- Prevent unauthorized long-term access
- Automate access lifecycle management
- Improve compliance and auditing practices

This is a common Linux administration and security operation in enterprise environments.

---

#  Step-by-Step Implementation

## 🔹 Step 1: Connect to the Application Server

```bash
ssh steve@stapp02.stratos.xfusioncorp.com
```

###  Explanation
Use SSH to securely connect to the target application server where the temporary user needs to be created.

---

## 🔹 Step 2: Create the Temporary User with Expiry Date

```bash
sudo useradd -e 2027-02-17 yousuf
```

###  Explanation
The `useradd` command creates a new Linux user account.

### Command Breakdown

| Option | Purpose |
|--------|---------|
| `-e` | Sets the account expiration date |
| `2027-02-17` | Expiry date in YYYY-MM-DD format |
| `yousuf` | Username |

After the specified date, the account will automatically become inactive.

---

## 🔹 Step 3: Verify User Creation

```bash
id yousuf
```

###  Explanation
This command confirms that the user account was successfully created on the system.

Expected output:

```bash
uid=1004(yousuf) gid=1004(yousuf) groups=1004(yousuf)
```

---

## 🔹 Step 4: Verify Account Expiry Configuration

```bash
sudo chage -l yousuf
```

###  Explanation
The `chage` command displays password and account aging information.

Expected output should include:

```bash
Account expires : Feb 17, 2027
```

This confirms that the expiration date has been applied successfully.

---

#  Additional Verification Commands

## Check User Entry
```bash
cat /etc/passwd | grep yousuf
```

## Check Expiry Information
```bash
sudo chage -l yousuf
```

## Modify Expiry Date
```bash
sudo usermod -e 2027-12-31 yousuf
```

## Remove User
```bash
sudo userdel -r yousuf
```

- Remove inactive accounts regularly
- Follow least-privilege access principles
- Avoid shared accounts across teams
- Audit temporary access periodically
