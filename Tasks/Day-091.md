# Task Overview

The Nautilus DevOps team wanted to automate the deployment of a simple Apache web server along with a sample web page. Unlike the previous task where `blockinfile` was used to manage multiple lines, this task focused on using the `lineinfile` module to insert a specific line at the top of a file.

The objective was to:

* Install Apache (httpd) on all application servers
* Start and enable the Apache service
* Create a sample index.html page
* Use the `lineinfile` module to add content at the beginning of the file
* Configure ownership and permissions
* Automate everything using Ansible

# What is Lineinfile Module?

The `lineinfile` module manages a single line inside a file.

Example:

```yaml
lineinfile:
```

It can:

* Add a line
* Remove a line
* Replace a line
* Insert a line at a specific location

---

# Lineinfile vs Blockinfile

| Lineinfile     | Blockinfile            |
| -------------- | ---------------------- |
| Single Line    | Multiple Lines         |
| Small Changes  | Large Blocks           |
| Simple Updates | Configuration Sections |

---

# Why DevOps Teams Use Lineinfile

Benefits:

* Precise file modifications

* Easy configuration management
* Reduced manual editing

# Step 5 – Add Playbook Content

```yaml
---
- name: Install and Configure Apache
  hosts: all
  become: yes

  tasks:

    - name: Install httpd
      yum:
        name: httpd
        state: present

    - name: Start and Enable httpd
      service:
        name: httpd
        state: started
        enabled: yes

    - name: Create index.html with initial content
      copy:
        dest: /var/www/html/index.html
        content: |
          This is a Nautilus sample file, created using Ansible!
        owner: apache
        group: apache
        mode: '0644'

    - name: Add welcome line at top
      lineinfile:
        path: /var/www/html/index.html
        line: "Welcome to xFusionCorp Industries!"
        insertbefore: BOF

    - name: Set ownership and permissions
      file:
        path: /var/www/html/index.html
        owner: apache
        group: apache
        mode: '0644'
```

# Common Mistakes

## Mistake 1 – Missing BOF

Wrong:

```yaml
lineinfile:
  line: "Welcome to xFusionCorp Industries!"
```

May append line elsewhere.

Correct:

```yaml
insertbefore: BOF
```

---

## Mistake 2 – Wrong Permission

Wrong:

```yaml
mode: '0777'
```

Correct:

```yaml
mode: '0644'
```

---

## Mistake 3 – Wrong Owner

Wrong:

```yaml
owner: root
group: root
```

Correct:

```yaml
owner: apache
group: apache
```

---

## Mistake 4 – Service Not Enabled

Wrong:

```yaml
state: started
```

Correct:

```yaml
enabled: yes
```
