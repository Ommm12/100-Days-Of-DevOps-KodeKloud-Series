# Day 100 – Create and Configure CloudWatch Alarm Using Terraform

---

# Task Overview

The final challenge of the 100 Days of DevOps journey focused on **Monitoring and Observability** — one of the most important responsibilities of a DevOps Engineer.

The Nautilus DevOps team needed to provision an EC2 instance and create a CloudWatch Alarm to continuously monitor CPU utilization. If CPU usage exceeded 90% for a continuous 5-minute period, CloudWatch should automatically trigger a notification through an existing SNS Topic.

The objective was to:

* Launch an EC2 instance
* Create a CloudWatch Alarm
* Monitor CPU Utilization
* Configure SNS notifications
* Use Terraform for complete automation
* Validate infrastructure state

# Step 1 – Create main.tf

```bash id="me6v35"
vi main.tf
```

Add:

```hcl id="6v6jv0"
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "5.91.0"
    }
  }
}

provider "aws" {
  region = "us-east-1"
}

data "aws_sns_topic" "datacenter_topic" {
  name = "datacenter-sns-topic"
}

resource "aws_instance" "datacenter_ec2" {

  ami = "ami-0c02fb55956c7d316"

  instance_type = "t2.micro"

  tags = {
    Name = "datacenter-ec2"
  }
}

resource "aws_cloudwatch_metric_alarm" "datacenter_alarm" {

  alarm_name = "datacenter-alarm"

  comparison_operator = "GreaterThanOrEqualToThreshold"

  evaluation_periods = 1

  metric_name = "CPUUtilization"

  namespace = "AWS/EC2"

  period = 300

  statistic = "Average"

  threshold = 90

  alarm_description = "Alarm when CPU exceeds 90 percent"

  alarm_actions = [
    data.aws_sns_topic.datacenter_topic.arn
  ]

  dimensions = {
    InstanceId = aws_instance.datacenter_ec2.id
  }
}
```

Save file.
