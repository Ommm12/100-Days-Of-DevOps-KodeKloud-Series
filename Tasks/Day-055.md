# Day 55 – Kubernetes Sidecar Containers

---

# Task Overview

The Nautilus DevOps team needed to implement the **Sidecar Container Pattern** for an Nginx web server running in Kubernetes.

The web server generates access and error logs, but storing them permanently was not required. However, developers needed visibility into recent logs for troubleshooting and debugging purposes.

To achieve this, a second container (Sidecar) was deployed within the same Pod. Both containers shared an `emptyDir` volume where Nginx writes logs and the Sidecar continuously reads them.

The objective was to:

* Create a Pod named `webserver`
* Create a shared `emptyDir` volume
* Deploy Nginx container
* Deploy Ubuntu sidecar container
* Mount shared volume in both containers
* Stream Nginx logs using the sidecar container

# What is a Sidecar Container?

A Sidecar is a helper container that runs alongside the main application container inside the same Pod.

It provides additional functionality such as:

* Log collection
* Monitoring
* Security scanning
* Data synchronization
* Proxy services

* Separation of concerns
* Independent functionality
* Better maintainability
* Easier debugging

# Step 3 – Add Pod Configuration

```yaml
apiVersion: v1
kind: Pod

metadata:
  name: webserver

spec:
  containers:

  - name: nginx-container
    image: nginx:latest

    volumeMounts:
    - name: shared-logs
      mountPath: /var/log/nginx

  - name: sidecar-container
    image: ubuntu:latest

    command:
    - sh
    - -c
    - while true; do cat /var/log/nginx/access.log /var/log/nginx/error.log; sleep 30; done

    volumeMounts:
    - name: shared-logs
      mountPath: /var/log/nginx

  volumes:
  - name: shared-logs
    emptyDir: {}
```

## Sidecar Command

```bash
while true;
do
cat /var/log/nginx/access.log \
/var/log/nginx/error.log;
sleep 30;
done
```

### Explanation

Infinite loop:

1. Reads access.log
2. Reads error.log
3. Waits 30 seconds
4. Repeats forever

# Common Mistakes

## Mistake 1 – Missing Shared Volume

Wrong:

```yaml
containers:
```

Without:

```yaml
volumes:
```

Sidecar cannot access logs.

---

## Mistake 2 – Different Mount Paths

Wrong:

```yaml
nginx:
/var/log/nginx

sidecar:
/tmp/logs
```

Correct:

```yaml
/var/log/nginx
```

Both containers must mount the same volume.

---

## Mistake 3 – Missing Infinite Loop

Wrong:

```bash
cat access.log
```

Container exits immediately.

Correct:

```bash
while true
```

keeps container running.

---

## Mistake 4 – Forgetting Image Tag

Wrong:

```yaml
image: nginx
```

Correct:

```yaml
image: nginx:latest
```
