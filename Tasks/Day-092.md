# Day 92 – Managing Jinja2 Templates Using Ansible

---

# Task Overview

The Nautilus DevOps team was developing an Ansible Role for Apache (httpd) installation and configuration. The role was almost complete, but it still required a Jinja2 template to dynamically generate a web page containing the target server's hostname.

Instead of hardcoding values, the goal was to use Ansible variables and templates to create dynamic configurations.

The objective was to:

* Run an existing Ansible role on App Server 1
* Create a Jinja2 template
* Use the `inventory_hostname` variable
* Deploy the template to Apache's document root
* Configure proper ownership and permissions
* Automate everything using Ansible Roles

Jinja2 is the template engine used by Ansible.

It allows:

* Variables
* Conditions
* Loops
* Dynamic configuration generation

# Step 6 – Create Tasks Directory

```bash

```

---

# Step 7 – Create Role Tasks

```bash
vi /home/thor/ansible/role/httpd/tasks/main.yml
```

Add:

```yaml
---
- name: Install httpd
  yum:
    name: httpd
    state: present

- name: Start and enable httpd
  service:
    name: httpd
    state: started
    enabled: yes

- name: Ensure document root exists
  file:
    path: /var/www/html
    state: directory

- name: Deploy index.html template
  template:
    src: index.html.j2
    dest: /var/www/html/index.html
    owner: tony
    group: tony
    mode: '0744'
```

Save file.

# Step 8 – Create Playbook

```bash

```


# Common Mistakes

## Mistake 1 – Wrong Role Path

Wrong:

```text
roles/httpd
```

Task expects:

```text
role/httpd
```

---

## Mistake 2 – Hardcoding Hostname

Wrong:

```html
This file was created using Ansible on stapp01
```

Correct:

```html
This file was created using Ansible on {{ inventory_hostname }}
```

---

## Mistake 3 – Missing Templates Directory

Wrong:

```text
role/httpd/index.html.j2
```

Correct:

```text
role/httpd/templates/index.html.j2
```

---

## Mistake 4 – Wrong Permissions

Wrong:

```yaml
mode: '0777'
```

Correct:

```yaml
mode: '0744'
```
