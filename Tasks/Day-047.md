# Day 47 – Dockerize and Deploy a Python Application

---

# Task Overview

The Nautilus DevOps team received a Python-based web application that needed to be containerized and deployed on an application server.

The application dependencies were already provided inside a `requirements.txt` file, and the objective was to create a Docker image, deploy it as a container, and expose the application through a custom host port.

This task introduced application containerization using Python, dependency management with pip, image building, and container deployment.

The objective was to:

* Create a Dockerfile
* Use a Python base image
* Install application dependencies
* Expose application port 8083
* Build a custom Docker image
* Deploy the application container
* Verify application accessibility

---

# Step 4 – Create Dockerfile

```bash
vi /python_app/Dockerfile
```

### Explanation

Creates the Docker build definition file.

---

# Step 5 – Add Dockerfile Configuration

```dockerfile
FROM python:3.12

WORKDIR /app

COPY src/requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY src/ .

EXPOSE 8083

CMD ["python","server.py"]
```

---

# Dockerfile Breakdown

## Base Image

```dockerfile
FROM python:3.12
```

Provides Python runtime environment.

---

## Working Directory

```dockerfile
WORKDIR /app
```

Sets application directory inside container.

---

## Copy Dependencies File

```dockerfile
COPY src/requirements.txt .
```

Copies dependency list into image.

---

## Install Dependencies

```dockerfile
RUN pip install --no-cache-dir -r requirements.txt
```

Installs all Python packages.

### Command Breakdown

| Part             | Meaning                |
| ---------------- | ---------------------- |
| pip install      | Install packages       |
| -r               | Read requirements file |
| requirements.txt | Dependency list        |
| --no-cache-dir   | Reduce image size      |

---

## Copy Application Code

```dockerfile
COPY src/ .
```

Copies application files into image.

---

## Expose Application Port

```dockerfile
EXPOSE 8083
```

Documents application listening port.

---

## Start Application

```dockerfile
CMD ["python","server.py"]
```

Starts Python application when container launches.

---

# Common Mistakes

## Mistake 1 – Dockerfile Created in Wrong Directory

Wrong:

```text
/home/tony/Dockerfile
```

Correct:

```text
/python_app/Dockerfile
```

---

## Mistake 2 – Forgetting requirements.txt

Wrong:

```dockerfile
COPY src/ .
```

without installing dependencies.

Correct:

```dockerfile
COPY src/requirements.txt .

RUN pip install -r requirements.txt
```

---

## Mistake 3 – Wrong Port Mapping

Wrong:

```bash
-p 8083:8094
```

Correct:

```bash
-p 8094:8083
```

---

## Mistake 4 – Incorrect Image Name

Wrong:

```text
python-app
```

Correct:

```text
nautilus/python-app
```

# Interview Questions

## 1. What is the purpose of requirements.txt?

Stores Python package dependencies required by the application.

---

## 2. Why use WORKDIR?

Defines the default working directory inside the container.

---

## 3. Difference Between CMD and RUN?

| RUN                   | CMD                             |
| --------------------- | ------------------------------- |
| Executes during build | Executes during container start |
| Creates image layer   | Starts application              |

---

## 4. How do you build a Docker image?

```bash
docker build -t image-name .
```

---

## 5. How do you expose an application?

```bash
docker run -p HOST_PORT:CONTAINER_PORT
```

Example:

```bash
docker run -p 8094:8083
```
