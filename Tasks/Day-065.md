# Day 65 – Deploy Redis Deployment on Kubernetes

---

# Task Overview

The Nautilus application development team identified performance bottlenecks in one of their Kubernetes-based applications. After investigating the issue, they concluded that introducing an in-memory caching solution would significantly improve application response times and reduce database load.

After evaluating several caching technologies, the team decided to use Redis for testing in their Kubernetes environment before moving to production.

The objective was to:

* Create a ConfigMap named `my-redis-config`
* Configure Redis memory settings
* Deploy Redis using a Kubernetes Deployment
* Mount ConfigMap and storage volumes
* Configure CPU resource requests
* Expose Redis on port `6379`
* Ensure the Redis Deployment is running successfully

# Understanding the Problem

Without Caching:

```text
Application
     │
     ▼
Database Query
     │
     ▼
Database
     │
     ▼
Response
```

Every request reaches the database.

---

With Redis Caching:

```text
Application
     │
     ▼
Redis Cache
     │
     ├── Cache Hit
     │      │
     │      ▼
     │   Response
     │
     └── Cache Miss
            │
            ▼
        Database
```

Result:

* Faster responses
* Reduced database load
* Improved scalability

# What is Redis?

Redis (Remote Dictionary Server) is an open-source in-memory data store used as:

* Cache
* Message Broker
* Session Store
* Key-Value Database

Redis stores data in RAM, making it significantly faster than disk-based databases.

# Step 7 – Add Deployment Configuration

```yaml
apiVersion: apps/v1
kind: Deployment

metadata:
  name: redis-deployment

spec:
  replicas: 1

  selector:
    matchLabels:
      app: redis

  template:
    metadata:
      labels:
        app: redis

    spec:
      containers:
      - name: redis-container
        image: redis:alpine

        ports:
        - containerPort: 6379

        resources:
          requests:
            cpu: "1"

        volumeMounts:
        - name: data
          mountPath: /redis-master-data

        - name: redis-config
          mountPath: /redis-master

      volumes:
      - name: data
        emptyDir: {}

      - name: redis-config
        configMap:
          name: my-redis-config
```

# Common Mistakes

## Mistake 1 – Wrong ConfigMap Name

Wrong:

```yaml
name: redis-config
```

Correct:

```yaml
name: my-redis-config
```

---

## Mistake 2 – Missing ConfigMap Volume

Without:

```yaml
configMap:
```

Redis configuration will not be available.

---

## Mistake 3 – Wrong CPU Request

Wrong:

```yaml
cpu: "500m"
```

Required:

```yaml
cpu: "1"
```

---

## Mistake 4 – Wrong Mount Path

Wrong:

```yaml
mountPath: /etc/redis
```

Required:

```yaml
/redis-master
```

---

## Mistake 5 – Wrong Redis Port

Wrong:

```yaml
containerPort: 8080
```

Correct:

```yaml
containerPort: 6379
```
