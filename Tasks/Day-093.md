# Day 93 – Using Ansible Conditionals

---

# Task Overview

The Nautilus DevOps team wanted to explore one of Ansible's most powerful features: **Conditionals (`when`)**. Instead of creating separate playbooks for different servers, they wanted a single playbook that could intelligently decide which task to execute based on the target server.

The objective was to:

* Run a playbook on all application servers
* Use Ansible conditional statements (`when`)
* Copy different files to different servers
* Set proper ownership and permissions
* Automate server-specific configurations from a single playbook

# What is a Conditional in Ansible?

A conditional allows Ansible to decide whether a task should run.

Example:

```yaml
when: inventory_hostname == "stapp01"
```

Meaning:

```text
Run this task ONLY on stapp01
```

---

# Why DevOps Teams Use Conditionals

Benefits:

* Dynamic automation
* Less code duplication
* Easier maintenance
* Better scalability

Example:

```text

      │
      ▼
One Playbook
      │
      ▼
Conditional Logic
```

# Step 5 – Add Playbook Content

```yaml
---
- name: Copy files using conditionals
  hosts: all
  become: yes

  tasks:

    - name: Ensure destination directory exists
      file:
        path: /opt/devops
        state: directory

    - name: Copy blog.txt to App Server 1
      copy:
        src: /usr/src/devops/blog.txt
        dest: /opt/devops/blog.txt
        owner: tony
        group: tony
        mode: '0777'
      when: ansible_nodename == "stapp01"

    - name: Copy story.txt to App Server 2
      copy:
        src: /usr/src/devops/story.txt
        dest: /opt/devops/story.txt
        owner: steve
        group: steve
        mode: '0777'
      when: ansible_nodename == "stapp02"

    - name: Copy media.txt to App Server 3
      copy:
        src: /usr/src/devops/media.txt
        dest: /opt/devops/media.txt
        owner: banner
        group: banner
        mode: '0777'
      when: ansible_nodename == "stapp03"
```

Save and exit.
