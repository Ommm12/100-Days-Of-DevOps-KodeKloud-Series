# Day 74 – Jenkins Database Backup Job

---

# Task Overview

The Nautilus DevOps team needed an automated solution for backing up a production database. Manual backups are error-prone and can easily be forgotten, so Jenkins was chosen to automate the process.

The objective was to:

* Create a Jenkins job named `database-backup`
* Generate a MySQL database dump
* Backup database `kodekloud_db01`
* Store backup using date-based naming
* Transfer backup to the Storage Server
* Schedule automatic execution every 10 minutes
* Verify successful backup creation

Database backups protect against:

* Accidental deletion
* Application failures
* Server crashes
* Data corruption
* Ransomware attacks

Without backups:


With backups:


# Interview Questions

## What is mysqldump?

A utility used to export MySQL databases into SQL files.

---

## Why automate backups?

To ensure backups occur consistently without manual intervention.

---

## What does date +%F return?

Example:

```text
2026-04-19
```

Format:

```text
YYYY-MM-DD
```

---

## Why store backups on another server?

Protects backups if the database server fails.

---

## What is SCP?

Secure Copy Protocol used to transfer files between Linux servers.
