# Day 83 – Troubleshoot and Create Ansible Playbook

---

# Task Overview

The Nautilus DevOps team found an incomplete Ansible setup on the Jump Host. The inventory file required troubleshooting, and a playbook needed to be created to automate file creation on App Server 3.

The objective was to:

* Troubleshoot and fix the inventory configuration
* Ensure Ansible can connect to App Server 3
* Create an Ansible playbook
* Create an empty file on the target server
* Execute the playbook successfully without additional arguments

# What is an Ansible Playbook?

An Ansible Playbook is a YAML file that defines automation tasks.

Examples:

* Install packages
* Manage services
* Configure servers
* Create files
* Deploy applications

Playbooks allow infrastructure to be managed as code.

* Consistency
* Repeatability
* Reduced Manual Work

# Creating the Playbook

## Step 7 – Create Playbook File

```bash
vi /home/thor/ansible/playbook.yml
```

---

## Step 8 – Add Playbook Content

```yaml
---
- name: Create file on App Server 3
  hosts: stapp03
  become: yes

  tasks:

    - name: Create empty file
      file:
        path: /tmp/file.txt
        state: touch
```

# Common Mistakes

## Mistake 1 – Host Key Verification Failure

Error:

```text
Host key checking is enabled
```

Fix:

```bash
ssh banner@stapp03
```

Accept fingerprint.

---

## Mistake 2 – Wrong Hostname

Wrong:

```yaml
hosts: app03
```

Correct:

```yaml
hosts: stapp03
```

---

## Mistake 3 – Missing Become

Without:

```yaml
become: yes
```

Some file operations may fail.

---

## Mistake 4 – Wrong State

Wrong:

```yaml
state: present
```

Correct:

```yaml
state: touch
```

For creating an empty file.
