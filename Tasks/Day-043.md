# Day 43 – Deploy an Nginx Container Using Docker

---

# Task Overview

The Nautilus DevOps team needed to deploy a lightweight Nginx web server inside a Docker container to host an application. The requirement was to pull the specified Nginx image, create a container, expose it on a custom host port, and ensure it remained in a running state.

This task introduced core Docker container lifecycle management concepts including image pulling, container creation, port mapping, and runtime verification.

The objective was to:

* Pull the `nginx:alpine-perl` image
* Create a container named `apps`
* Map host port `8086` to container port `80`
* Keep the container running
* Verify container deployment

# Step-by-Step Implementation

## Step 1 – Connect to Application Server

```bash
ssh tony@stapp01
```

### Explanation

---

# Step 2 – Verify Docker Service

```bash
sudo systemctl status docker
```

### Explanation

Ensures Docker daemon is running before deploying containers.

---

# Step 3 – Pull Nginx Image

```bash
sudo docker pull nginx:alpine-perl
```

### Explanation

Downloads the required image from Docker Hub.

---

# Command Breakdown

| Part        | Meaning          |
| ----------- | ---------------- |
| docker      | Docker CLI       |

# Step 4 – Verify Image Download

```bash

```

### Example Output

```text

```

### Explanation

---

# Step 5 – Create and Run Container

```bash
sudo docker run -d \
--name apps \
-p 8086:80 \
nginx:alpine-perl
```

### Explanation

Creates and starts the container.

# Common Mistakes

## Mistake 1 – Wrong Port Mapping

Wrong:

```bash
-p 80:8086
```

Correct:

```bash
-p 8086:80
```

---

## Mistake 2 – Forgetting Detached Mode

Wrong:

```bash
docker run nginx:alpine-perl
```

Terminal gets attached.

Correct:

```bash
docker run -d nginx:alpine-perl
```

---

## Mistake 3 – Wrong Image Tag

Wrong:

```bash
nginx:latest
```

Task required:

```bash
nginx:alpine-perl
```

---

## Mistake 4 – Container Name Mismatch

Wrong:

```bash
--name nginx
```

Correct:

```bash
--name apps
```
