# Day 11 – Apache Tomcat Deployment with ROOT.war

## Task Overview
The Nautilus application development team planned to deploy a Java-based application on App Server 1 using Apache Tomcat.

The objective was to:
- Install Tomcat
- Configure it to run on port 5000
- Deploy the provided ROOT.war application
- Verify application accessibility from the base URL

---

# Objective

- Install Apache Tomcat on App Server 1
- Configure Tomcat to use port 5000
- Deploy ROOT.war from Jump Host
- Verify application availability using curl

---

# Why This Task Matters

Apache Tomcat is one of the most widely used Java application servers in production environments.

This task demonstrates:
- Java application deployment
- Web server configuration
- WAR deployment lifecycle
- Production service validation

---

# Step-by-Step Implementation

## Step 1: Connect to App Server 1

```bash
ssh tony@stapp01.stratos.xfusioncorp.com
```

---

## Step 2: Install Tomcat

```bash
sudo yum install -y tomcat
```

---

## Step 3: Configure Tomcat Port

Open configuration file:

```bash
sudo vi /etc/tomcat/server.xml
```

Find:

```xml
Connector port="8080"
```

Change to:

```xml
Connector port="5000"
```

---

## Step 4: Start and Enable Tomcat

```bash
sudo systemctl start tomcat
sudo systemctl enable tomcat
```

---

## Step 5: Copy ROOT.war from Jump Host

From Jump Host:

```bash
scp /tmp/ROOT.war tony@stapp01.stratos.xfusioncorp.com:/tmp
```

---

## Step 6: Deploy Application

On App Server 1:

```bash
sudo cp /tmp/ROOT.war /var/lib/tomcat/webapps/
```

---

## Step 7: Restart Tomcat

```bash
sudo systemctl restart tomcat
```

---

## Step 8: Verify Port Availability

```bash
sudo ss -tulnp | grep 5000
```

---

## Step 9: Test Application

```bash
curl http://stapp01:5000
```

Expected output:

```bash
Welcome to xFusionCorp Industries!
```

---

# Additional Verification Commands

## Check Tomcat Service
```bash
sudo systemctl status tomcat
```

## Verify Deployed Application
```bash
ls -l /var/lib/tomcat/webapps/
```

## Check Tomcat Logs
```bash
sudo journalctl -u tomcat
```
