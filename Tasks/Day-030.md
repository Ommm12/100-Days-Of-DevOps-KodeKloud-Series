# Task Overview

The Nautilus application development team was working on the repository:

```bash
/usr/src/kodekloudrepos/news
```

The repository was originally created for testing purposes. Multiple commits had been added during testing, but the team decided to remove all unnecessary commits and restore the repository to a clean state.

After resetting the history, the updated branch needed to be pushed to the remote repository.

# Important Concept – Git Reset

## What is Git Reset?

Git Reset moves the current branch pointer to a specified commit.

It can:

- Remove commits
- Undo local history
- Restore repository state

---

# Types of Git Reset

## Soft Reset

```bash
git reset --soft HEAD~1
```

Removes commit but keeps changes staged.

---

## Mixed Reset

```bash
git reset HEAD~1
```

Removes commit and unstages changes.

---

## Hard Reset

```bash
git reset --hard HEAD~1
```

Removes:

- Commit
- Staging Area
- Working Directory Changes

---

# Why Force Push Is Needed

After reset:

Local History:

```text
A ── B
```

Remote History:

```text
A ── B ── C ── D ── E
```

Git detects mismatch.

Normal push:

```bash
git push
```

fails.

Force push:

```bash
git push --force
```

overwrites remote history.

---

# Git Reset vs Git Revert

| Git Reset | Git Revert |
|------------|------------|
| Removes commits | Creates new commit |
| Rewrites history | Preserves history |
| Requires force push | Normal push |
| Dangerous on shared repos | Safe on shared repos |

---

# Real DevOps Insight

Git Reset is commonly used for:

- Test repositories
- Local development cleanup
- Removing accidental commits
- Preparing clean branches

Production teams usually prefer:

```bash
git revert
```

because it preserves history.

# Interview Questions

## 1. What does Git Reset do?

Moves the current branch pointer to a specified commit.

---

## 2. What is the difference between Soft and Hard Reset?

Soft reset preserves changes, while hard reset removes commits and working directory changes.

---

## 3. Why is Force Push required after Reset?

Because reset rewrites history and local history no longer matches the remote branch.

---

## 4. Is Git Reset safe for shared repositories?

Generally no.

Git Revert is preferred for shared repositories.

---

## 5. What happens after `git reset --hard`?

Git removes:

- Commit history after target commit
- Staged changes
- Working directory modifications
