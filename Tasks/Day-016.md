# Day 16 – Nginx Load Balancer Configuration

## Task Overview
The production support team planned to migrate the application to a high-availability architecture using a Load Balancer server.

---

# Objective

- Install Nginx on LBR server
- Configure load balancing
- Route traffic to all app servers
- Maintain Apache backend services

---

# Step-by-Step Implementation

## Step 1: Install Nginx

```bash
sudo yum install -y nginx
```

---

## Step 2: Configure Load Balancer

```bash
sudo vi /etc/nginx/nginx.conf
```

Configured upstream block:

```nginx
upstream backend {
    server stapp01;
    server stapp02;
    server stapp03;
}
```

---

## Step 3: Configure Proxying

```nginx
location / {
    proxy_pass http://backend;
}
```

---

## Step 4: Restart Nginx

```bash
sudo systemctl restart nginx
sudo systemctl enable nginx
```

---

## Step 5: Verify Backend Services

```bash
sudo systemctl status httpd
```

---

- Load balancing concepts
- Reverse proxy configuration
- High availability architecture
- Traffic distribution strategies

- Load balancing configured successfully
- Traffic distributed across app servers
