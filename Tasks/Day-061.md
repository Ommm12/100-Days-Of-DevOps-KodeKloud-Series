# Day 61 – Init Containers in Kubernetes

---

# Task Overview

The Nautilus DevOps team needed to deploy an application on a Kubernetes cluster that required some setup tasks to be completed before the main application container could start.

To solve this requirement, Kubernetes Init Containers were used. Init containers run before application containers and are commonly used to prepare configuration files, initialize data, perform dependency checks, or execute setup scripts.

The objective was to:

* Create a Deployment named `ic-deploy-devops`
* Configure an Init Container to create a file before the application starts
* Share data between Init Container and Main Container using an `emptyDir` volume
* Verify that the Main Container can read data written by the Init Container

# Step 3 – Add Deployment Configuration

```yaml
apiVersion: apps/v1
kind: Deployment

metadata:
  name: ic-deploy-devops

spec:
  replicas: 1

  selector:
    matchLabels:
      app: ic-nautilus

  template:
    metadata:
      labels:
        app: ic-nautilus

    spec:

      volumes:
      - name: ic-volume-nautilus
        emptyDir: {}

      initContainers:
      - name: ic-msg-nautilus
        image: ubuntu:latest

        command:
        - /bin/bash
        - -c
        - echo Init Done - Welcome to xFusionCorp Industries > /ic/ecommerce

        volumeMounts:
        - name: ic-volume-nautilus
          mountPath: /ic

      containers:
      - name: ic-main-nautilus
        image: ubuntu:latest

        command:
        - /bin/bash
        - -c
        - while true; do cat /ic/ecommerce; sleep 5; done

        volumeMounts:
        - name: ic-volume-nautilus
          mountPath: /ic
```

# Common Mistakes

## Mistake 1 – Wrong Volume Mount

Wrong:

```yaml
mountPath: /data
```

Result:

```text
File Not Found
```

Mount paths must match.

---

## Mistake 2 – Missing Volume Definition

Without:

```yaml
volumes:
```

Pod creation fails.

---

## Mistake 3 – Init Container Never Finishes

Wrong command:

```bash
while true
```

Result:

```text
Main Container Never Starts
```

Init containers must complete.

---

## Mistake 4 – Wrong File Name

Init Container:

```text
/ic/ecommerce
```

Main Container:

```text
/ic/media
```

Result:

```text
No such file or directory
```

File names must match.

# Interview Questions

## 1. What is an Init Container?

A special container that runs before application containers to perform initialization tasks.

---

## 2. When does an Init Container run?

Before any regular container starts.

---

## 3. Can a Main Container start before an Init Container finishes?

No. All Init Containers must complete successfully first.

---

## 4. What is emptyDir?

A temporary volume shared between containers in the same Pod.
