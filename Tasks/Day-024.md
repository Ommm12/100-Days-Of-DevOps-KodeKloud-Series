# Day 24 – Create a New Git Branch

---

# Task Overview

The Nautilus developers were actively working on the repository located at:

```bash
/usr/src/kodekloudrepos/cluster
```

The development team wanted to implement new features separately without affecting the existing stable codebase. To achieve this, a new branch needed to be created from the master branch.

### Requirements

- Create a new branch named:

```bash
xfusioncorp_cluster
```

- Repository location:

```bash
/ usr/src/kodekloudrepos/cluster
```

- Create the branch from the `master` branch
- Do not modify existing source code

---

# Infrastructure Details

| Server | Hostname | User |
|---|---|---|
| Storage Server | ststor01.stratos.xfusioncorp.com | natasha |

---

# Step-by-Step Implementation

## Step 1 – Connect to Storage Server

```bash
ssh natasha@ststor01
```

### Explanation

The `ssh` command establishes a secure connection to the Storage Server where the repository exists.

---

# Step 2 – Navigate to Repository

```bash
cd /usr/src/kodekloudrepos/cluster
```

### Explanation

Moves into the Git repository directory where the branch operation will be performed.

---

# Step 3 – Verify Existing Branches

```bash
git branch
```

### Expected Output

```bash
* master
```

### Explanation

Displays available branches and confirms that the current branch is `master`.

---

# Step 4 – Handle Dubious Ownership Issue (If Appears)

Sometimes Git may show:

```bash
fatal: detected dubious ownership in repository
```

To resolve:

```bash
git config --global --add safe.directory /usr/src/kodekloudrepos/cluster
```

### Explanation

Git security checks may block repositories owned by another user.  
This command marks the repository as safe for operations.

---

# Step 5 – Create New Branch

```bash
sudo git checkout -b xfusioncorp_cluster master
```

### Explanation

Creates and switches to a new branch from the `master` branch.

### Command Breakdown

| Part | Meaning |
|---|---|
| `git checkout` | Switch branches |
| `-b` | Create new branch |
| `xfusioncorp_cluster` | New branch name |
| `master` | Source branch |

---

# Step 6 – Verify Branch Creation

```bash
git branch
```

### Expected Output

```bash
master
* xfusioncorp_cluster
```

### Explanation

Confirms that the new branch has been created successfully and is currently active.

# Important Concept – Git Branching

## What is a Branch?

A branch is an independent line of development in Git.

Branches allow developers to:
- develop features safely
- isolate changes
- avoid affecting production code

---

# Real DevOps Insight

Branching strategies are heavily used in:

- Feature development
- Bug fixing
- Release management
- CI/CD workflows

Typical workflow:

```text
Master Branch → Create Feature Branch → Develop → Test → Merge
```
