# Day 44 – Deploy an Apache Web Server Using Docker Compose

---

# Task Overview

The Nautilus application development team provided static website content that needed to be hosted using an Apache web server running inside a Docker container.

To simplify container deployment and management, Docker Compose was used to define the entire container configuration in a YAML file.

The objective was to:

* Create a Docker Compose file
* Deploy an Apache HTTP Server container
* Map host port 3003 to container port 80
* Mount the host directory `/opt/data`
* Ensure the container is running successfully
* Verify website accessibility

# What is Docker Compose?

Docker Compose is a tool used to define and manage containers using YAML files.

Instead of running long Docker commands:

```bash
docker run ...
```

everything can be described inside:

```yaml
docker-compose.yml
```

# Step-by-Step Implementation

## Step 1 – Connect to Application Server

```bash
ssh tony@stapp01
```

### Explanation

Connects securely to the target application server.

---

# Step 2 – Verify Docker Service

```bash
sudo systemctl status docker
```

### Explanation

Ensures Docker daemon is running before deploying containers.

---

# Step 3 – Create Docker Directory

```bash
sudo mkdir -p /opt/docker
```

### Explanation

Creates the required directory to store the compose file.

### Command Breakdown

| Part        | Meaning                             |
| ----------- | ----------------------------------- |
| mkdir       | Create directory                    |
| -p          | Create parent directories if needed |
| /opt/docker | Target directory                    |

---

# Step 4 – Create Docker Compose File

```bash
sudo vi /opt/docker/docker-compose.yml
```

### Explanation

Creates the Docker Compose configuration file.

---

# Step 5 – Add Docker Compose Configuration

```yaml
services:
  web:
    image: httpd:latest
    container_name: httpd
    ports:
      - "3003:80"
    volumes:
      - /opt/data:/usr/local/apache2/htdocs
```

---

# Docker Compose File Breakdown

## Service Definition

```yaml
services:
```

Defines all application services.

---

## Image

```yaml
image: httpd:latest
```

Uses the latest Apache HTTP Server image.

---

## Container Name

```yaml
container_name: httpd
```

Assigns a fixed name to the container.

---

## Port Mapping

```yaml
ports:
  - "3003:80"
```

Maps:

```text
Host Port 3003
        │
        ▼
Container Port 80
```

Users access:

```text
http://server-ip:3003
```

---

## Volume Mapping

```yaml
volumes:
  - /opt/data:/usr/local/apache2/htdocs
```

Maps host files into Apache document root.

```text
Host Directory
/opt/data
      │
      ▼
Container Directory
/usr/local/apache2/htdocs
```

---

# Step 6 – Verify Compose File

```bash
cat /opt/docker/docker-compose.yml
```

### Explanation

Displays file contents for verification.

---

# Step 7 – Deploy Container

```bash
docker compose -f /opt/docker/docker-compose.yml up -d
```

### Explanation

Creates and starts the container.

### Command Breakdown

| Option         | Meaning               |
| -------------- | --------------------- |
| docker compose | Compose CLI           |
| -f             | Specify file          |
| up             | Create/start services |
| -d             | Run in background     |

---

# Common Mistakes

## Mistake 1 – Wrong Container Name

Wrong:

```yaml
container_name: apache
```

Correct:

```yaml
container_name: httpd
```

---

## Mistake 2 – Wrong Port Mapping

Wrong:

```yaml
8080:80
```

Correct:

```yaml
3003:80
```

---

## Mistake 3 – Wrong Volume Path

Wrong:

```yaml
/data:/usr/local/apache2/htdocs
```

Correct:

```yaml
/opt/data:/usr/local/apache2/htdocs
```

---

## Mistake 4 – Using docker-compose Instead of docker compose

Modern Docker uses:

```bash
docker compose
```

instead of:

```bash
docker-compose
```
