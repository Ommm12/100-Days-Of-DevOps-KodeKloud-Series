Normally:

```text

        │
        ▼

```

After Hook:

```text
Developer Pushes Code
        │
        ▼

        │
        ▼
Release Tag Created
```

This automates release management.

---

# What is a Git Hook?

Git Hooks are scripts that Git executes automatically when specific events occur.

Examples:

| Hook | Trigger |
|--------|--------|
| pre-commit | Before commit |
| post-commit | After commit |
| pre-push | Before push |
| post-update | After repository update |

# Step 6 – Create Post-Update Hook

```bash
vi post-update
```

Insert:

```bash

DATE=$(date +%F)

git --git-dir=/opt/news.git tag release-$DATE
```

Save:

```text
ESC
:wq
```

# Common Mistakes Faced During This Task

## Mistake 1 – Wrong Hook Directory

Wrong:

```bash
/usr/src/kodekloudrepos/news/.git/hooks
```

Correct:

```bash
/opt/news.git/hooks
```

Because:

```text
Pushes arrive at the bare repository
```

---

## Mistake 2 – Forgetting Execute Permission

Wrong:

```bash
vi post-update
```

Without:

```bash
chmod +x post-update
```

Hook never executes.

---

## Mistake 3 – Creating Hook in Wrong File

Wrong:

```bash
post-update.sample
```

Correct:

```bash
post-update
```

---

## Mistake 4 – Not Testing the Hook

Always create:

```bash
trigger.txt
```

commit and push.

---

## Mistake 5 – Running git tag in Working Repository

The tag is created inside:

```bash
/opt/news.git
```

Verify there.

# Interview Questions

## 1. What is a Git Hook?

A Git Hook is a script that executes automatically when specific Git events occur.

---

## 2. What does the post-update hook do?

Runs after a successful push updates references in a repository.

---

## 3. Why was the hook created in `/opt/news.git/hooks`?

Because the repository receiving the push is the bare repository.

---

## 4. Why is `chmod +x` required?

Git only executes hook scripts that have execute permission.

---

## 5. What are release tags used for?

Release tags mark important versions of software for deployment and rollback purposes.
