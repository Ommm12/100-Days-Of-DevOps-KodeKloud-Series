# Day 69 – Install Jenkins Plugins

---

# Task Overview

The Nautilus DevOps team recently deployed a Jenkins server to automate CI/CD workflows. Before creating jobs and pipelines, they needed essential plugins installed to support source code management and GitLab integration.

The objective was to:

* Login to Jenkins
* Install Git Plugin
* Install GitLab Plugin
* Restart Jenkins if required
* Verify plugins are installed successfully

# Why These Plugins?

## Git Plugin

Provides:

```text
Git Repositories
Git Checkout
Git Polling
Git Credentials
```

---

## GitLab Plugin

Provides:

```text
GitLab Integration
Webhooks
Build Triggers
Merge Request Support
```

# Step-by-Step Implementation

## Step 1 – Login to Jenkins

Open:

```text
Jenkins Button
```

Credentials:

```text
Username: admin
Password: Adm!n321
```

---

## Step 2 – Open Plugin Manager

Navigate:

```text
Manage Jenkins
        │
        ▼
Plugins
```

---

## Step 3 – Search Git Plugin

Select:

```text
Git
```

---

## Step 4 – Search GitLab Plugin

Select:

```text
GitLab
```

---

## Step 5 – Install Plugins

Click:

```text
Install
```

or

```text
Install without restart
```

---

## Step 6 – Restart Jenkins

If prompted:

```text
Restart Jenkins when installation is complete
```

---

## Step 7 – Verify Installation

Navigate:

```text
Manage Jenkins
        │
        ▼
Plugins
        │
        ▼
Installed Plugins
```

Verify:

```text
Git
GitLab
```

appear in installed plugins list.
