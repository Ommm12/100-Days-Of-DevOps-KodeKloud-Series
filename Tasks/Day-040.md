# Day 40 – Install and Configure Apache Inside a Docker Container

---

# Task Overview

One of the Nautilus DevOps engineers was configuring services inside a running Docker container named:

```bash
kkloud
```

on App Server 2. Before completing the work, the engineer went on leave, and the remaining tasks needed to be completed.

The objective was to:

- Install Apache (`apache2`) inside the container
- Change Apache listening port from:

```bash
80
```

to:

```bash
8083
```

- Ensure Apache listens on all interfaces
- Start Apache service
- Keep the container running

# Step-by-Step Implementation

## Step 1 – Connect to App Server

```bash
ssh steve@stapp02
```

### Explanation

# Step 2 – Verify Container

```bash
docker ps
```

### Example Output

```bash
CONTAINER ID   IMAGE     NAMES

abc123def456   ubuntu    kkloud
```

### Explanation

Confirms container is running.

---

# Step 3 – Access Container

```bash
docker exec -it kkloud bash
```

### Explanation

Opens an interactive shell inside the container.

---

# Step 4 – Update Package Repository

```bash
apt update
```

### Explanation

Refreshes package index before installation.

---

# Step 5 – Install Apache

```bash
apt install apache2 -y
```

### Explanation

Installs Apache HTTP Server.

### Command Breakdown

| Part | Meaning |
|----------|----------|
| apt | Package manager |
| install | Install package |
| apache2 | Apache package |
| -y | Auto confirm |

---

# Step 6 – Verify Installation

```bash
apache2 -v
```

### Example Output

```bash
Server version: Apache/2.4.x
```

### Explanation

Confirms successful installation.

---

# Step 7 – Modify Apache Port Configuration

Open:

```bash
vi /etc/apache2/ports.conf
```

### Default

```apache
Listen 80
```

### Change To

```apache
Listen 8083
```

Save:

```text
ESC
:wq
```

---

# Why This Change?

Default:

```text
Port 80
```

Required:

```text
Port 8083
```

Apache must listen on the specified port.

---

# Step 8 – Update Virtual Host Configuration

Open:

```bash
vi /etc/apache2/sites-enabled/000-default.conf
```

Find:

```apache
<VirtualHost *:80>
```

Replace with:

```apache
<VirtualHost *:8083>
```

Save file.

---

# Why Update Virtual Host?

Apache listens on:

```apache
<VirtualHost *:80>
```

by default.

Changing only:

```apache
Listen 8083
```

is not enough.

Virtual Host must match.

---

# Step 9 – Start Apache Service

```bash
service apache2 start
```

or

```bash

```

### Explanation

Starts Apache inside the container.

# Common Mistakes

## Mistake 1 – Running `vi` Outside Container

Wrong:

```bash
vi /etc/apache2/ports.conf
```

on host.

Must enter:

```bash
docker exec -it kkloud bash
```

first.

---

## Mistake 2 – Changing Only ports.conf

Wrong:

```apache
Listen 8083
```

without updating:

```apache
<VirtualHost *:8083>
```

Apache may fail.

---

## Mistake 3 – Forgetting to Start Apache

Wrong:

```bash
apt install apache2 -y
```

Only installs package.

Must start:

```bash
service apache2 start
```

---

## Mistake 4 – Stopping Container Accidentally

Wrong:

```bash
docker stop kkloud
```

Container must remain running.

---

## Mistake 5 – Command Not Found for vi

Some containers do not have:

```bash
vi
```

installed.

Alternative:

```bash
nano
```

or

```bash
sed
```

can be used.
