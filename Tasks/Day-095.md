# Day 95 – Create Security Group Using Terraform

---

# Task Overview

As part of the AWS migration journey, the Nautilus DevOps team needed to secure their future cloud infrastructure. Before deploying applications, servers, or databases, proper network access control must be configured.

For this task, the objective was to create an AWS Security Group using Terraform that allows:

* HTTP traffic on Port 80
* SSH traffic on Port 22

The Security Group needed to be created inside the **Default VPC** in the **us-east-1** region.

# What is a Security Group?

A Security Group is AWS's virtual firewall.

It controls:

* Incoming Traffic (Ingress)
* Outgoing Traffic (Egress)

Applied to:

* EC2 Instances
* Load Balancers
* Databases
* Other AWS Resources

# Step 2 – Create main.tf

```bash
vi main.tf
```

---

# Step 3 – Add Terraform Configuration

```hcl
terraform {
  required_providers {
    aws = {
      source = "hashicorp/aws"
    }
  }
}

provider "aws" {
  region = "us-east-1"
}

data "aws_vpc" "default" {
  default = true
}

resource "aws_security_group" "devops_sg" {

  name        = "devops-sg"

  description = "Security group for Nautilus App Servers"

  vpc_id      = data.aws_vpc.default.id

  ingress {
    description = "HTTP"

    from_port   = 80

    to_port     = 80

    protocol    = "tcp"

    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    description = "SSH"

    from_port   = 22

    to_port     = 22

    protocol    = "tcp"

    cidr_blocks = ["0.0.0.0/0"]
  }

  egress {

    from_port   = 0

    to_port     = 0

    protocol    = "-1"

    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = {
    Name = "devops-sg"
  }
}
```

Save and exit.

# Common Mistakes

## Mistake 1 – Creating Security Group Without VPC

Wrong:

```hcl
resource "aws_security_group" "sg" {}
```

Without:

```hcl
vpc_id
```

Terraform may fail.

---

## Mistake 2 – Wrong Port

Wrong:

```hcl
from_port = 8080
```

Task requires:

```hcl
from_port = 80
```

---

## Mistake 3 – Missing SSH Rule

Validation checks:

```text
Port 22
```

Must exist.

---

## Mistake 4 – Wrong CIDR

Wrong:

```hcl
cidr_blocks = ["10.0.0.0/24"]
```

Correct:

```hcl
cidr_blocks = ["0.0.0.0/0"]
```
