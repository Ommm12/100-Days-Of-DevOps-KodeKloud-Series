# Day 85 – Create Files on App Servers Using Ansible

---

# Task Overview

The Nautilus DevOps team needed to automate file creation across all application servers using Ansible. The goal was not only to create the file but also to configure proper ownership and permissions based on each application's server user.

The objective was to:

* Create an Ansible inventory containing all application servers
* Create a playbook to create a file on all servers
* Set file permissions
* Configure ownership dynamically per server
* Validate successful deployment

```bash

```

---

# Step 5 – Add Playbook Content

```yaml
---
- name: Create data file on all application servers
  hosts: all
  become: yes

  tasks:

    - name: Create data.txt on App Server 1
      file:
        path: /home/data.txt
        state: touch
        owner: tony
        group: tony
        mode: '0644'
      when: inventory_hostname == "stapp01"

    - name: Create data.txt on App Server 2
      file:
        path: /home/data.txt
        state: touch
        owner: steve
        group: steve
        mode: '0644'
      when: inventory_hostname == "stapp02"

    - name: Create data.txt on App Server 3
      file:
        path: /home/data.txt
        state: touch
        owner: banner
        group: banner
        mode: '0644'
      when: inventory_hostname == "stapp03"
```

Save file.

# Common Mistakes

## Mistake 1 – Wrong Permissions

Wrong:

```yaml
mode: '777'
```

Correct:

```yaml
mode: '0644'
```

---

## Mistake 2 – Missing Become

Without:

```yaml
become: yes
```

Ownership changes fail.

---

## Mistake 3 – Wrong Owner

Example:

```yaml
owner: root
```

Task requires:

```yaml
owner: tony
```

for App Server 1.

---

## Mistake 4 – Missing Conditional

Without:

```yaml
when:
```

All servers receive the same owner.

# Interview Questions

## 1. What does state: touch do?

Creates a file if it does not exist and updates timestamp if it already exists.

---

## 2. What is the purpose of the file module?

To manage files, directories, ownership, permissions, and symlinks.

---

## 3. What does 0644 mean?

```text
Owner  → rw-
Group  → r--
Others → r--
```

---

## 4. Why use when conditions?

To execute tasks only on specific hosts.

---

## 5. Why is become: yes needed?

To perform privileged operations such as changing file ownership.
