# Day 37 – Copy File from Docker Host to Running Container

---

# Task Overview

The Nautilus DevOps team had confidential encrypted data stored on App Server 2. A running Docker container named:

```bash
ubuntu_latest
```

needed access to this encrypted file.

The objective was to:

- Locate the encrypted file on the Docker host
- Copy the file into the running container
- Preserve file integrity
- Ensure the file was copied without modification

---

# Infrastructure Details

| Server | Hostname | User |
|----------|----------|----------|
| App Server 2 | stapp02 | steve |

Container:

```bash
ubuntu_latest
```

Source File:

```bash
/tmp/nautilus.txt.gpg
```

Destination:

```bash
/home/
```

inside the container.

---

# Requirements

Copy:

```bash
/tmp/nautilus.txt.gpg
```

from Docker host

to

```bash
/home/
```

inside:

```bash
ubuntu_latest
```

container.

---

# Understanding the Problem

Current Situation:

```text
Docker Host
│
├── /tmp/nautilus.txt.gpg
│
└── ubuntu_latest Container
      │
      └── /home/
```

Goal:

```text
Docker Host
│
├── /tmp/nautilus.txt.gpg
│
└── ubuntu_latest Container
      │
      └── /home/nautilus.txt.gpg
```

---

# What is Docker Copy?

Docker provides:

```bash
docker cp
```

which allows file transfer between:

- Host → Container
- Container → Host

without entering the container.

---

# Step-by-Step Implementation

## Step 1 – Connect to App Server

```bash
ssh steve@stapp02
```

### Explanation

Connects securely to App Server 2.

---

# Step 2 – Verify Running Container

```bash
docker ps
```

### Example Output

```bash
CONTAINER ID   IMAGE     NAMES
e4a1bcf2a12d  ubuntu    ubuntu_latest
```

### Explanation

Displays currently running containers.

Verify:

```bash
ubuntu_latest
```

exists and is running.

---

# Step 3 – Verify Source File

```bash
ls -l /tmp/nautilus.txt.gpg
```

### Example Output

```bash
-rw-r--r-- 1 root root 256 May 20 12:00 /tmp/nautilus.txt.gpg
```

### Explanation

Confirms the encrypted file exists.

---

# Step 4 – Copy File to Container

```bash
docker cp /tmp/nautilus.txt.gpg ubuntu_latest:/home/
```

### Explanation

Copies the encrypted file into the container.

### Command Breakdown

| Part | Meaning |
|----------|----------|
| docker cp | Docker copy command |
| /tmp/nautilus.txt.gpg | Source file |
| ubuntu_latest | Container name |
| /home/ | Destination directory |

---

# Step 5 – Verify File Inside Container

```bash
docker exec ubuntu_latest ls -l /home/
```

### Example Output

```bash
-rw-r--r-- 1 root root 256 nautilus.txt.gpg
```

### Explanation

Confirms successful file transfer.

---

# Step 6 – Verify Container Remains Running

```bash
docker ps
```

Expected:

```bash
ubuntu_latest
```

still running.

---

# Important Concept – Docker CP

## What Does docker cp Do?

Transfers files between:

```text
Host ↔ Container
```

without:

```bash
docker exec
```

or mounting volumes.

---

# Common Docker Copy Operations

## Host → Container

```bash
docker cp file.txt container:/tmp/
```

---

## Container → Host

```bash
docker cp container:/tmp/file.txt .
```

---

## Copy Entire Directory

```bash
docker cp project/ container:/app/
```

---

# Common Mistakes

## Mistake 1 – Using Wrong Container Name

Wrong:

```bash
docker cp file ubuntu:/home/
```

Always verify:

```bash
docker ps
```

first.

---

## Mistake 2 – Copying to Wrong Path

Wrong:

```bash
docker cp file ubuntu_latest:/tmp
```

Task required:

```bash
/home/
```

---

## Mistake 3 – Modifying File

Wrong:

```bash
vi nautilus.txt.gpg
```

Task explicitly required:

```text
No Modification
```

---

## Mistake 4 – Stopping Container

Wrong:

```bash
docker stop ubuntu_latest
```

Container must remain running.

# Interview Questions

## 1. What is docker cp?

A Docker command used to transfer files between the host and containers.

---

## 2. Can docker cp copy directories?

Yes.

Example:

```bash
docker cp app/ container:/tmp/
```

---

## 3. How do you copy a file from host to container?

```bash
docker cp file.txt container:/path/
```

---

## 4. How do you copy a file from container to host?

```bash
docker cp container:/path/file.txt .
```

---

## 5. Does docker cp require entering the container?

No.

Files can be copied directly.
