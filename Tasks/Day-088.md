# Task Overview

The Nautilus DevOps team wanted to automate the installation and configuration of an Apache web server across all application servers. In addition, they needed to deploy a sample web page using Ansible's `blockinfile` module while ensuring proper ownership, permissions, and service management.

The objective was to:

* Install Apache (httpd) on all application servers
* Start and enable the Apache service
* Create and manage a web page using the Blockinfile module
* Configure proper ownership and permissions
* Automate everything using Ansible

# What is Blockinfile Module?

The `blockinfile` module inserts and manages blocks of text inside files.

Example:

```yaml
blockinfile:
```

Unlike:

```yaml
lineinfile:
```

which manages a single line, `blockinfile` manages multiple lines together.

---

# Why DevOps Teams Use Blockinfile

Benefits:

* Configuration consistency
* Easy automation
* Controlled file modifications
* Idempotent changes

Example:

# Step 5 – Add Playbook Content

```yaml
---
- name: Install and Configure Apache
  hosts: all
  become: yes

  tasks:

    - name: Install httpd
      yum:
        name: httpd
        state: present

    - name: Start and Enable httpd
      service:
        name: httpd
        state: started
        enabled: yes

    - name: Create index.html
      file:
        path: /var/www/html/index.html
        state: touch

    - name: Add content using blockinfile
      blockinfile:
        path: /var/www/html/index.html
        block: |
          Welcome to XfusionCorp!

          This is Nautilus sample file, created using Ansible!

          Please do not modify this file manually!

    - name: Set ownership and permissions
      file:
        path: /var/www/html/index.html
        owner: apache
        group: apache
        mode: '0655'
```

# Common Mistakes

## Mistake 1 – Using Empty Marker

Wrong:

```yaml
marker: ""
```

Task explicitly forbids custom or empty markers.

---

## Mistake 2 – Forgetting Service Enable

Wrong:

```yaml
state: started
```

Correct:

```yaml
state: started
enabled: yes
```

---

## Mistake 3 – Wrong Ownership

Wrong:

```yaml
owner: root
group: root
```

Correct:

```yaml
owner: apache
group: apache
```

---

## Mistake 4 – Wrong Permission

Wrong:

```yaml
mode: '0644'
```

Correct:

```yaml
mode: '0655'
```

# Interview Questions

## 1. What is the Blockinfile Module?

It manages multiple lines of text as a single block inside a file.

---

## 2. What is the difference between lineinfile and blockinfile?

| lineinfile    | blockinfile    |
| ------------- | -------------- |
| Single Line   | Multiple Lines |
| Small Changes | Large Blocks   |

---

## 3. How do you start and enable a service in Ansible?

```yaml
service:
  name: httpd
  state: started
  enabled: yes
```

---

## 4. Why use become: yes?

To perform administrative tasks such as package installation and service management.

## 5. What does mode 0655 represent?

```text
Owner  → rw-
Group  → r-x
Others → r-x
```
