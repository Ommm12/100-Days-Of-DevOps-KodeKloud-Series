# Day 64 – Fix Python App Deployed on Kubernetes Cluster

---

# Task Overview

The Nautilus DevOps team had already deployed a Python Flask application on a Kubernetes cluster. However, due to a configuration issue, the application was not accessible.

The deployment and service already existed, but the application needed troubleshooting and correction to ensure it could be accessed through the specified NodePort.

The objective was to:

* Investigate the existing Deployment
* Identify the application's listening port
* Verify Service configuration
* Fix incorrect targetPort settings
* Configure NodePort as `32345`
* Ensure the application becomes accessible

# Common Mistakes

## Mistake 1 – Wrong TargetPort

Wrong:

```yaml
targetPort: 80
```

Actual App:

```yaml
targetPort: 5000
```

Result:

```text
Application Not Reachable
```

---

## Mistake 2 – Wrong NodePort

Wrong:

```yaml
nodePort: 30000
```

Required:

```yaml
32345
```

---

## Mistake 3 – Pod Not Running

Check:

```bash
kubectl get pods
```

Status must be:

```text
Running
```

---

## Mistake 4 – No Service Endpoint

Check:

```bash
kubectl get endpoints
```

If empty:

```text
Selector mismatch
```

Service cannot find Pods.
