# Day 54 – Kubernetes Shared Volumes

---

# Task Overview

The Nautilus DevOps team needed to create a Kubernetes Pod containing two containers that share data through a common volume. This setup is commonly used when multiple containers within the same Pod need access to the same files.

The task involved creating a shared `emptyDir` volume, mounting it into both containers at different paths, and verifying that a file created in one container becomes immediately available in the other container.

The objective was to:

* Create a Pod named `volume-share-nautilus`
* Deploy two Ubuntu containers
* Create a shared `emptyDir` volume
* Mount the volume in both containers
* Create a test file in the first container
* Verify the file appears in the second container

# What is an emptyDir Volume?

An `emptyDir` volume is created when the Pod starts and exists as long as the Pod is running.

Characteristics:

* Shared among containers in the same Pod
* Temporary storage
* Deleted when Pod is removed
* Useful for inter-container communication

---

# Step 3 – Add Pod Configuration

```yaml
apiVersion: v1
kind: Pod

metadata:
  name: volume-share-nautilus

spec:
  containers:

  - name: volume-container-nautilus-1
    image: ubuntu:latest
    command: ["/bin/bash","-c","sleep 3600"]
    volumeMounts:
    - name: volume-share
      mountPath: /tmp/news

  - name: volume-container-nautilus-2
    image: ubuntu:latest
    command: ["/bin/bash","-c","sleep 3600"]
    volumeMounts:
    - name: volume-share
      mountPath: /tmp/apps

  volumes:
  - name: volume-share
    emptyDir: {}
```

# Common Mistakes

## Mistake 1 – Missing Volume Mount

Wrong:

```yaml
containers:
- name: container1
```

Without:

```yaml
volumeMounts:
```

Shared storage won't work.

---

## Mistake 2 – Different Volume Names

Wrong:

```yaml
volume1
volume2
```

Containers must mount the same volume.

Correct:

```yaml
volume-share
```

---

## Mistake 3 – Forgetting Sleep Command

Without:

```yaml
sleep 3600
```

Container exits immediately.

---

## Mistake 4 – Wrong Mount Path

Task required:

```text
Container 1:
/tmp/news

Container 2:
/tmp/apps
```

# Interview Questions

## 1. What is an emptyDir volume?

A temporary Kubernetes volume created when a Pod starts and deleted when the Pod is removed.

---

## 2. Can multiple containers share an emptyDir volume?

Yes.

That is one of its primary use cases.

---

## 3. What happens to emptyDir when Pod is deleted?

All data is deleted.

---

## 4. Why use sleep command?

Keeps containers alive for testing and debugging.

---

## 5. How do you access a specific container in a Pod?

```bash
kubectl exec -it <pod-name> -c <container-name> -- bash
```
