Before running Ansible playbooks in production environments, DevOps teams must ensure that communication between the Ansible Controller and managed nodes is working correctly. For this task, the Nautilus DevOps team needed to establish password-less SSH authentication and verify connectivity to App Server 1 using the Ansible Ping Module.

The objective was to:

* Configure password-less SSH authentication
* Verify connectivity between controller and managed node
* Test Ansible communication using the ping module
* Ensure App Server 1 is reachable through Ansible

# What is the Ansible Ping Module?

The Ansible Ping Module does not send traditional ICMP ping packets.

Instead, it:

1. Connects through SSH
2. Executes Python on the remote host
3. Returns:

```json
{
  "ping": "pong"
}
```

if communication is successful.

# Interview Questions

## 1. What does the Ansible ping module do?

It verifies connectivity and remote execution capability between the controller and managed node.

---

## 2. Does Ansible ping use ICMP?

No.

It uses:

```text
SSH + Python
```

---

## 3. What is password-less SSH?

Authentication using SSH keys instead of passwords.

---

## 4. Why is password-less SSH important?

It enables fully automated infrastructure management.
