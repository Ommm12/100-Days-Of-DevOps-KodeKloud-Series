# Day 60 – Persistent Volumes in Kubernetes

---

# Task Overview

The Nautilus DevOps team needed to deploy a web application on Kubernetes while ensuring that application data remained available even if the Pod was recreated.

To achieve this, Kubernetes Persistent Volumes (PV) and Persistent Volume Claims (PVC) were used. Unlike `emptyDir` volumes, which are deleted when a Pod is removed, Persistent Volumes provide long-term storage that survives Pod restarts and recreation.

The objective was to:

* Create a Persistent Volume named `pv-devops`
* Create a Persistent Volume Claim named `pvc-devops`
* Create a Pod named `pod-devops`
* Mount the Persistent Volume inside an Apache web server container
* Create a NodePort Service named `web-devops`
* Expose the application using NodePort `30008`

# What is a Persistent Volume (PV)?

A Persistent Volume is storage managed by Kubernetes.

Characteristics:

* Independent of Pods
* Survives Pod recreation
* Can be reused
* Provides long-term storage

---

# What is a Persistent Volume Claim (PVC)?

A PVC is a request for storage.

Think of it as:

```text
Pod
 │
 ▼
PVC
 │
 ▼
PV
```

The Pod does not directly use the PV.

Instead:

```text
Pod → PVC → PV
```

# Step 11 – Add Pod Configuration

```yaml
apiVersion: v1
kind: Pod

metadata:
  name: pod-devops
  labels:
    app: web-devops

spec:
  containers:
  - name: container-devops
    image: httpd:latest

    ports:
    - containerPort: 80

    volumeMounts:
    - name: devops-storage
      mountPath: /usr/local/apache2/htdocs

  volumes:
  - name: devops-storage
    persistentVolumeClaim:
      claimName: pvc-devops
```

# Common Mistakes

## Mistake 1 – Storage Class Mismatch

Wrong:

```yaml
PV:
manual

PVC:
standard
```

Result:

```text
PVC Pending
```

Both must match.

---

## Mistake 2 – PVC Request Larger Than PV

Wrong:

```yaml
PV: 4Gi
PVC: 10Gi
```

PVC cannot bind.

---

## Mistake 3 – Missing Volume Mount

Without:

```yaml
volumeMounts:
```

Container cannot access storage.

---

## Mistake 4 – Missing Labels

Without:

```yaml
labels:
  app: web-devops
```

Service cannot find Pod.
