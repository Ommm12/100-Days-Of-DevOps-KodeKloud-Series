# Day 94 – Create VPC Using Terraform

---

# Task Overview

The Nautilus DevOps team began their AWS cloud migration journey by creating the most fundamental networking component in AWS — a **Virtual Private Cloud (VPC)**.

Every AWS infrastructure deployment starts with networking. Before launching EC2 instances, databases, load balancers, or Kubernetes clusters, a VPC must exist to provide network isolation and security.

The objective was to:

* Create a VPC using Terraform
* Name the VPC `devops-vpc`
* Configure an IPv4 CIDR block
* Deploy resources in the `us-east-1` region
* Manage infrastructure using Infrastructure as Code (IaC)

```bash
cd /home/bob/terraform
```

---

# Step 2 – Create main.tf

```bash
vi main.tf
```

---

# Step 3 – Add Terraform Configuration

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
    }
  }
}

provider "aws" {
  region = "us-east-1"
}

resource "aws_vpc" "devops_vpc" {

  cidr_block = "10.0.0.0/16"

  tags = {
    Name = "devops-vpc"
  }
}
```

Save and exit.

# Common Mistakes

## Mistake 1 – Wrong Region

Wrong:

```hcl
region = "us-west-1"
```

Correct:

```hcl
region = "us-east-1"
```

---

## Mistake 2 – Invalid CIDR

Wrong:

```hcl
cidr_block = "10.0.0.0"
```

Correct:

```hcl
cidr_block = "10.0.0.0/16"
```

---

## Mistake 3 – Missing Provider

Wrong:

```hcl
resource "aws_vpc" "devops_vpc"
```

Without provider block.

Terraform cannot connect to AWS.

---

## Mistake 4 – Forgetting Apply

Running:

```bash
terraform plan
```

does not create resources.

Must run:

```bash
terraform apply
```
