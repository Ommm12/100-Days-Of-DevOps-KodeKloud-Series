# Day 19 – Hosting Multiple Static Websites on Apache

## Task Overview
The infrastructure team needed to host two static websites on a single Apache server using custom directories.

---

# Objective

- Install Apache
- Configure custom port 6100
- Host multiple websites
- Validate website accessibility

---

# Step-by-Step Implementation

## Step 1: Install Apache

```bash
sudo yum install -y httpd
```

---

## Step 2: Configure Port

```bash
Listen 6100
```

---

## Step 3: Deploy Website Files

```bash
sudo mv /tmp/news /var/www/html/
sudo mv /tmp/apps /var/www/html/
```

---

## Step 4: Start Apache

```bash
sudo systemctl start httpd
sudo systemctl enable httpd
```

---

## Step 5: Validate Websites

```bash
curl http://localhost:6100/news/
curl http://localhost:6100/apps/
```

---

# Key Learnings

- Apache virtual directory hosting
- Multi-site hosting strategies
- Static content deployment
- Custom port configuration

---

# Final Outcome

- Multiple websites hosted successfully
- Apache serving content on custom port
- Static website deployment validated
