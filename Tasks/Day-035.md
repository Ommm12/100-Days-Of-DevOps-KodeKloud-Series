# Step-by-Step Implementation

## Step 1 – Connect to Application Server

```bash
ssh tony@stapp01
```

### Explanation

Connects securely to the target application server.

---

# Step 2 – Switch to Root User

```bash
sudo su -
```

### Explanation

Docker installation requires administrative privileges.

---

# Step 3 – Verify Operating System

```bash
cat /etc/os-release
```

### Explanation

Useful for identifying package manager and Docker installation method.

---

# Step 4 – Install Docker Package

For CentOS/RHEL:

```bash
yum install docker -y
```

or

```bash
yum install docker-ce -y
```

### Explanation

Installs Docker Engine and required dependencies.

### Command Breakdown

| Part | Meaning |
|---------|---------|
| yum | Package manager |
| install | Install package |
| docker | Docker package |
| -y | Auto confirm |

---

# Step 5 – Verify Installation

```bash
docker --version
```

### Example Output

```bash
Docker version 26.x.x
```

### Explanation

Confirms Docker was installed successfully.

---

# Step 6 – Start Docker Service

```bash
systemctl start docker
```

### Explanation

Starts the Docker daemon.

Docker must be running before containers can be created.

---

# Step 7 – Verify Docker Service Status

```bash
systemctl status docker
```

### Expected Output

```text
active (running)
```

### Explanation

Confirms Docker service is operational.

---

# Step 8 – Enable Docker Service

```bash
systemctl enable docker
```

### Explanation

Configures Docker to start automatically during system boot.

---

# Step 9 – Verify Docker Process

```bash
ps -ef | grep docker
```

### Example Output

```bash
dockerd
```

### Explanation

Confirms Docker daemon is running.

---

# Step 10 – Verify Docker Functionality

```bash
docker info
```

### Explanation

Displays Docker configuration and runtime information.

# Common Mistakes

## Mistake 1 – Forgetting to Start Docker

Wrong:

```bash
docker ps
```

Output:

```text
Cannot connect to Docker daemon
```

Reason:

```bash
systemctl start docker
```

was not executed.

---

## Mistake 2 – Forgetting Enable

Wrong:

```bash
systemctl start docker
```

Only starts current session.

Correct:

```bash
systemctl enable docker
```

for reboot persistence.

---

## Mistake 3 – Installing Wrong Package

Always verify package name.

Common names:

```bash
docker
docker-ce
```

---

## Mistake 4 – Running Docker Commands as Non-Privileged User

May result in:

```text
Permission denied
```

Use:

```bash
sudo
```

or configure Docker group.
